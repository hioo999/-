# 在线提词器专业化前端页面组件拆分

## 1. 文档目标

本文档用于指导前端将在线提词器专业化 V0.1 页面拆成可开发组件，明确页面结构、组件职责、状态、事件和接口依赖。

前端开发原则：

- 先跑通录制闭环，后补充智能能力。
- 播放、暂停、调速、跳段、全屏必须稳定。
- 输入编辑态和播放控制态要避免快捷键冲突。
- 本地草稿优先，云端草稿作为增强能力。
- 全屏态以低干扰和高可读性为第一优先级。

## 2. 页面路由

```text
/teleprompter
/teleprompter?source=script&scriptId=:id
/teleprompter?source=video-package&packageId=:id
/teleprompter?draftId=:id
```

| 路由 | 页面状态 | 说明 |
|---|---|---|
| /teleprompter | 空状态或本地草稿恢复 | 独立提词器入口 |
| /teleprompter?source=script&scriptId=:id | 编辑态 | 从 AI 脚本进入 |
| /teleprompter?source=video-package&packageId=:id | 编辑态 | 从短视频发布包进入 |
| /teleprompter?draftId=:id | 编辑态或暂停态 | 从云端草稿进入 |

## 3. 页面状态机

```text
empty
editing
countdown
playing
paused
interaction_paused
fullscreen_playing
fullscreen_paused
finishing
finished
error
```

状态说明：

| 状态 | 说明 |
|---|---|
| empty | 没有脚本内容，展示引导 |
| editing | 用户编辑脚本和设置 |
| countdown | 开始前倒计时 |
| playing | 普通模式播放中 |
| paused | 普通模式暂停中 |
| interaction_paused | 直播互动暂停 |
| fullscreen_playing | 全屏播放中 |
| fullscreen_paused | 全屏暂停中 |
| finishing | 结束确认中 |
| finished | 本次提词结束 |
| error | 出现不可恢复错误 |

## 4. 顶层页面组件

### 4.1 TeleprompterPage

用途：提词器页面容器，负责读取路由参数、加载脚本、维护主状态。

职责：

- 解析 source、scriptId、packageId、draftId。
- 加载来源脚本或草稿。
- 管理脚本内容、设置、播放状态、滚动位置。
- 调度本地草稿保存。
- 分发埋点事件。
- 控制全屏进入和退出。

状态：

```text
loading
empty
ready
saving
save_failed
source_load_failed
```

接口依赖：

- `GET /api/scripts/:id`
- `GET /api/video-packages/:id/teleprompter-script`
- `GET /api/teleprompter/drafts/:id`
- `POST /api/teleprompter/drafts`
- `PUT /api/teleprompter/drafts/:id`

验收：

- 无参数时可进入空状态。
- scriptId 有效时可完整带入脚本。
- packageId 有效时可完整带入口播脚本。
- 加载失败时显示错误和返回入口。

## 5. 空状态组件

### 5.1 TeleprompterEmptyState

用途：无脚本内容时引导用户开始。

内容：

- 粘贴脚本入口。
- 导入 txt/md 文件入口。
- 恢复最近草稿入口。
- 查看示例脚本入口。
- 快捷键说明入口。

事件：

| 事件 | 说明 |
|---|---|
| onPasteScript | 打开粘贴脚本输入区 |
| onImportFile | 打开文件导入弹窗 |
| onRestoreDraft | 恢复最近草稿 |
| onUseExample | 加载示例脚本 |
| onOpenShortcutHelp | 打开快捷键说明 |

验收：

- 无脚本时不显示播放控制。
- 粘贴脚本后进入 editing 状态。
- 恢复草稿失败时显示提示，不阻塞用户粘贴。

## 6. 编辑区组件

### 6.1 ScriptEditorPanel

用途：编辑脚本标题和正文。

字段：

| 字段 | 类型 | 规则 |
|---|---|---|
| title | string | 非必填，最多50字 |
| content | string | 必填，最多30000字 |
| wordCount | number | 根据正文自动计算 |
| paragraphCount | number | 根据段落识别结果计算 |

状态：

```text
idle
editing
empty
exceeded
saving
saved
save_failed
```

事件：

| 事件 | 说明 |
|---|---|
| onTitleChange | 修改标题 |
| onContentChange | 修改正文 |
| onClear | 清空脚本 |
| onCopy | 复制脚本 |
| onSaveDraft | 保存草稿 |

验收：

- 正文为空时禁止开始提词。
- 超过30000字时提示超限。
- 编辑过程中不触发全局播放快捷键。

### 6.2 ScriptMetaBar

用途：展示脚本状态和统计信息。

展示：

- 字数。
- 段落数。
- 预估时长。
- 保存状态。
- 来源标签。

验收：

- 字数变化实时更新。
- 保存失败时有明确提示。

## 7. 设置组件

### 7.1 TeleprompterSettingsPanel

用途：管理显示和播放设置。

设置项：

| 设置 | 可选值 | 默认值 |
|---|---|---|
| fontSize | small、medium、large、xlarge | large |
| lineHeight | compact、normal、loose | normal |
| scrollSpeed | 1-10 | 5 |
| theme | dark、light、contrast | dark |
| countdownEnabled | true、false | true |
| countdownSeconds | 3、5、10 | 3 |
| mirrorMode | true、false | false |

事件：

| 事件 | 说明 |
|---|---|
| onFontSizeChange | 修改字号 |
| onLineHeightChange | 修改行距 |
| onSpeedChange | 修改速度 |
| onThemeChange | 切换主题 |
| onCountdownToggle | 开关倒计时 |
| onMirrorToggle | 开关镜像模式 |

验收：

- 设置变更实时影响预览区。
- 播放中调速立即生效。
- 刷新后设置可恢复。

## 8. 预览与播放组件

### 8.1 TeleprompterPreview

用途：展示提词正文，承担编辑态预览和播放态滚动。

输入：

| 字段 | 说明 |
|---|---|
| content | 脚本正文 |
| paragraphs | 段落列表 |
| settings | 显示设置 |
| playbackStatus | 播放状态 |
| currentScrollPosition | 当前滚动位置 |

事件：

| 事件 | 说明 |
|---|---|
| onScrollPositionChange | 滚动位置变化 |
| onCurrentParagraphChange | 当前段落变化 |
| onReachEnd | 滚动到末尾 |

验收：

- 30000字以内可正常展示。
- 播放、暂停、恢复不丢位置。
- 主题、字号、行距切换后不清空滚动位置。

### 8.2 CountdownOverlay

用途：开始播放前倒计时。

状态：

```text
idle
counting
cancelled
completed
```

验收：

- 倒计时结束后自动播放。
- 用户可取消倒计时。

## 9. 控制组件

### 9.1 TeleprompterControlBar

用途：提供录制中高频操作。

按钮：

- 播放/暂停。
- 降速。
- 加速。
- 上一段。
- 下一段。
- 互动暂停。
- 全屏。
- 结束。

状态：

```text
ready
playing
paused
interaction_paused
fullscreen
```

验收：

- 控制按钮在播放中始终可达。
- 禁用项有明确禁用态。
- 结束按钮必须触发二次确认。

### 9.2 FullscreenControlOverlay

用途：全屏态控制浮层。

显示规则：

- 鼠标移动时显示。
- 鼠标静止3秒后隐藏。
- 快捷键触发时短暂显示反馈。
- 触屏设备点击屏幕显示。

验收：

- 浮层不遮挡核心提词内容。
- Esc 可退出全屏。
- 退出后返回原播放位置。

## 10. 段落组件

### 10.1 ParagraphNavigator

用途：展示段落列表并支持跳转。

字段：

| 字段 | 说明 |
|---|---|
| id | 段落ID |
| index | 段落序号 |
| previewText | 段落前30字 |
| wordCount | 段落字数 |
| isActive | 是否当前段落 |

事件：

| 事件 | 说明 |
|---|---|
| onParagraphClick | 点击跳转到段落 |
| onPrevParagraph | 上一段 |
| onNextParagraph | 下一段 |

验收：

- 当前段落高亮。
- 长稿段落列表可滚动。
- 点击段落后正文定位准确。

## 11. 互动暂停组件

### 11.1 InteractionPausePanel

用途：直播中临时暂停正文，输入互动话术。

字段：

| 字段 | 说明 |
|---|---|
| temporaryNote | 临时话术 |
| pausedPosition | 暂停位置 |
| contextPreview | 原文上下文 |

事件：

| 事件 | 说明 |
|---|---|
| onResume | 恢复正文 |
| onTemporaryNoteChange | 修改临时话术 |
| onClearTemporaryNote | 清空临时话术 |
| onCopyTemporaryNote | 复制临时话术 |

验收：

- 进入互动暂停后正文停止滚动。
- 恢复后从暂停位置继续。
- 临时话术默认不写回原脚本。

## 12. 弹窗组件

### 12.1 ImportScriptModal

用途：导入 txt/md 文件。

状态：

```text
idle
uploading
parsing
success
failed
unsupported
empty_file
```

验收：

- txt、md 可解析为脚本正文。
- 不支持格式有明确提示。
- 解析成功后进入 editing 状态。

### 12.2 ShortcutHelpModal

用途：展示快捷键说明。

快捷键：

| 快捷键 | 操作 |
|---|---|
| Space | 播放/暂停 |
| ArrowUp | 降低速度 |
| ArrowDown | 提高速度 |
| ArrowLeft | 上一段 |
| ArrowRight | 下一段 |
| F | 进入/退出全屏 |
| Esc | 退出全屏或关闭浮层 |
| I | 互动暂停/恢复正文 |
| M | 镜像模式 |

验收：

- 首次进入播放态可提示。
- 用户关闭后本地记忆。

### 12.3 FinishConfirmModal

用途：结束提词前确认。

按钮：

- 确认结束。
- 继续提词。

验收：

- 点击结束必须先弹窗确认。
- 确认结束后进入 finished 状态。

### 12.4 FinishSummaryPanel

用途：展示本次提词统计和后续动作。

展示：

- 本次时长。
- 完成比例。
- 脚本字数。
- 平均速度。
- 重新播放。
- 复制脚本。
- 提交出片。
- 返回来源页。

验收：

- 统计数据与本次播放过程一致。
- 有来源页时可返回来源页。

## 13. Hook与工具函数建议

| 名称 | 职责 |
|---|---|
| useTeleprompterState | 管理主状态机 |
| useTeleprompterPlayback | 管理播放、暂停、速度、滚动 |
| useTeleprompterDraft | 管理本地和云端草稿 |
| useTeleprompterShortcuts | 管理快捷键 |
| useFullscreen | 封装 Fullscreen API |
| useParagraphs | 解析段落和当前段落 |
| useTeleprompterAnalytics | 上报埋点 |

工具函数：

| 函数 | 职责 |
|---|---|
| parseParagraphs | 解析段落 |
| estimateDuration | 估算口播时长 |
| normalizeScriptText | 清理脚本文本 |
| clampScrollSpeed | 限制速度范围 |
| getFocusableInputState | 判断当前是否处于输入态 |


```json

    "lineHeight": "normal",
    "scrollSpeed": 5,
    "theme": "dark",
    "mirrorMode": false
  },
  "currentParagraphIndex": 0,
  "currentScrollPosition": 120,

}
```
