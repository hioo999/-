# 在线提词器专业化Sprint任务拆分与验收清单

## 1. 文档目标

本文档用于将《在线提词器专业化 PRD V0.1》拆分为可执行的 Sprint 任务，明确前端、后端、测试、产品和设计的交付边界。

Sprint 目标：

```text
跑通脚本导入 -> 编辑预览 -> 提词播放 -> 全屏控制 -> 暂停恢复 -> 结束保存的基础闭环。
```

## 2. Sprint范围

### 2.1 必须交付

| 模块 | 交付内容 | 优先级 |
|---|---|---|
| 提词器入口 | 空白入口、AI脚本入口、短视频发布包入口 | P0 |
| 脚本编辑 | 标题、正文、字数统计、基础校验 | P0 |
| 提词预览 | 字号、行距、主题实时预览 | P0 |
| 播放控制 | 播放、暂停、速度调节、段落跳转 | P0 |
| 全屏模式 | 进入、退出、浮层控制、位置保持 | P0 |
| 本地草稿 | 保存脚本、设置、播放位置 | P0 |
| 快捷键 | Space、方向键、F、Esc | P0 |
| 结束流程 | 二次确认、本次统计、后续动作 | P0 |
| 异常状态 | 空内容、超长、保存失败、全屏不支持 | P0 |

### 2.2 可选交付

| 模块 | 交付内容 | 优先级 |
|---|---|---|
| 文件导入 | txt、md 导入与解析 | P1 |
| 互动暂停 | 暂停正文、临时话术、恢复正文 | P1 |
| 倒计时 | 开始前3秒倒计时 | P1 |
| 镜像模式 | 正文水平镜像 | P1 |

### 2.3 明确不做

| 模块 | 不做原因 |
|---|---|
| 语音跟读 | 技术复杂，暂不阻塞录制闭环 |
| 语音识别自动滚动 | 对环境噪音敏感，稳定性风险高 |
| 遥控器硬件 | 专业版能力，先用键盘快捷键覆盖 |
| 云端协作 | 团队版再做 |
| AI实时改稿 | 先保证播放稳定 |

## 7. 接口建议

### 7.1 获取AI脚本

```text
GET /api/scripts/:id
```

返回字段：

| 字段 | 说明 |
|---|---|
| id | 脚本ID |
| title | 脚本标题 |
| content | 脚本正文 |
| source | 来源类型 |
| updatedAt | 更新时间 |

### 7.2 获取短视频发布包脚本

```text
GET /api/video-packages/:id/teleprompter-script
```

返回字段：

| 字段 | 说明 |
|---|---|
| packageId | 发布包ID |
| title | 脚本标题 |
| content | 口播脚本正文 |
| platform | 平台 |
| durationEstimate | 预估时长 |

### 7.3 保存提词草稿

```text
POST /api/teleprompter/drafts
PUT /api/teleprompter/drafts/:id
```

请求字段：

| 字段 | 说明 |
|---|---|
| title | 草稿标题 |
| content | 脚本正文 |
| settings | 字号、行距、速度、主题等设置 |
| currentParagraphIndex | 当前段落 |
| currentScrollPosition | 当前滚动位置 |
| source | 来源 |
| sourceId | 来源ID |

### 7.4 获取提词草稿

```text
GET /api/teleprompter/drafts/recent
GET /api/teleprompter/drafts/:id
```

## 11. 风险与处理

| 风险 | 影响 | 处理方式 |
|---|---|---|
| 全屏API浏览器差异 | 全屏体验不一致 | 不支持时隐藏按钮并给出提示 |
| 长稿滚动卡顿 | 录制中断 | 限制字数，优化滚动实现，必要时分段渲染 |
| 快捷键与输入冲突 | 用户编辑受影响 | 输入框聚焦时禁用全局快捷键 |
| 本地草稿丢失 | 用户脚本损失 | 自动保存失败时提示复制备份 |
| 手机屏幕过小 | 控制区遮挡正文 | 手机端底部控制栏可折叠 |
| 直播中误触结束 | 录制中断 | 结束操作二次确认 |

## 13. Sprint通过标准

必须全部满足：

- 用户可以从空白入口进入提词器。
- 用户可以从 AI 脚本或短视频脚本进入提词器。
- 用户可以编辑脚本并调整显示设置。
- 用户可以开始、暂停、恢复、调速、跳段。
- 用户可以进入和退出全屏，播放位置不丢失。
- 用户刷新页面后可以恢复本地草稿。
- 长稿 30000 字以内可正常滚动。
- 关键异常状态有明确提示。
- 桌面端、平板横屏、手机竖屏可完成基础提词。

## 14. Sprint不通过条件

任一出现则不通过：

- 无法进入提词器页面。
- 脚本无法编辑或无法开始提词。
- 播放暂停不稳定。
- 全屏退出后丢失脚本或播放位置。
- 刷新后草稿完全丢失且无提示。
- 输入框中按空格会触发播放控制。
- 长稿明显卡顿导致无法录制。
- 移动端无法完成基础播放和暂停。
