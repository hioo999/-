# IP全案系统P0-AI提示词模板清单

## 1. 文档目标

本文档定义P0阶段所有AI生成动作的提示词模板结构，供前端、后端、提示词工程和测试对齐。

P0提示词原则：

- 所有生成都必须引用IP资产和内容母稿。
- 平台适配必须明确平台风格，不允许同一文案硬套多平台。
- 所有输出必须结构化，方便前端渲染和用户编辑。
- 所有生成必须包含禁用表达和合规提醒。
- 图片提示词必须包含用途、构图、文字、风格和禁止事项。

## 2. 通用上下文模板

所有文本生成任务都应带入以下上下文：

```text
【IP资产】
IP名称：{{ipName}}
IP类型：{{ipType}}
行业：{{industry}}
目标用户：{{targetAudience}}
商业目标：{{businessGoal}}
表达风格：{{tone}}
转化路径：{{conversionPath}}
禁用表达：{{forbiddenExpressions}}

【内容策略】
IP定位：{{positioning}}
平台分工：{{platformRoles}}
核心痛点：{{corePainPoints}}

【选题】
选题标题：{{topicTitle}}
所属栏目：{{columnName}}
内容目标：{{contentGoal}}
目标平台：{{platforms}}

【内容母稿】
用户痛点：{{painPoint}}
核心观点：{{coreViewpoint}}
论证逻辑：{{logic}}
案例素材：{{cases}}
金句：{{goldenSentences}}
转化动作：{{conversionAction}}

【要求】
所有内容必须符合IP定位和平台风格。
不得出现禁用表达。
不得做绝对化承诺。
输出必须结构化。
```

## 3. IP内容策略生成

### 输入

```text
IP资产
目标用户
商业目标
主平台
辅助平台
当前阶段
```

### 提示词模板

```text
你是IP内容策略顾问。请根据以下IP资料，生成适合多平台运营的内容策略。

{{通用IP资料}}

请输出：
1. IP定位一句话
2. 目标用户画像
3. 用户核心痛点
4. 账号核心价值
5. 差异化表达
6. 公众号平台分工
7. 小红书平台分工
8. 抖音平台分工
9. 视频号平台分工
10. 朋友圈平台分工
11. 转化路径
12. 禁做方向

要求：
表达要具体，不要空泛。
平台分工要有明显差异。
转化路径要可执行。
```

### 输出结构

```json
{
  "positioning": "",
  "targetUserProfile": "",
  "corePainPoints": [],
  "accountValue": "",
  "differentiation": "",
  "platformRoles": {},
  "conversionPath": "",
  "forbiddenDirections": []

## 4. 栏目矩阵生成

推荐频率

栏目之间要有区分。
必须覆盖涨粉、信任、种草、转化四类目标中的至少三类。

```

## 17. P0提示词验收标准

- 每个生成动作都有明确输入和输出结构。
- 公众号、小红书、抖音、视频号、朋友圈风格必须明显不同。
- 图片生成提示词必须包含用途、构图、风格、图中文字和禁止事项。
- 所有文本生成必须带入IP资产、内容策略和内容母稿。
- 所有输出都必须可被前端结构化渲染。
- 提词器导入稿只生成文本，不修改提词器功能。
