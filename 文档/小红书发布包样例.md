# 小红书发布包样例

## 1. 文档目标

本文档定义P0阶段小红书发布包的标准结构和示例内容，供产品、设计、前端、后端、AI提示词和测试统一验收。

P0小红书不做自动发布，只做：

```text
文案生成 + 图片生成 + 发布包预览 + 图片下载 + 文案复制
```

## 2. 发布包结构

标准小红书发布包包含：

```text
封面图
正文配图3-8张
标题候选
最终标题
正文文案
标签
评论区引导
私信承接话术
每张图片的用途
每张图片的图中文字
每张图片的生成提示词
风险提醒
```

## 7. 正文文案

```text
很多人选职业方向的时候，最容易犯一个错误：上来就问哪个行业更热门。

但真实情况是，热门行业不等于适合你，也不等于你进得去，更不等于你能长期留下来。

我看过很多同学和职场新人，听了很多建议，刷了很多经验贴，最后还是更迷茫。原因不是信息不够，而是缺少判断标准。

选职业方向前，先看这3件事。

第一，看你的筹码。

你的学历、专业、城市、实习经历、表达能力、家庭资源、抗压能力，这些都是真实筹码。方向不是靠热情选的，是靠筹码匹配出来的。

第二，看行业门槛。

一个行业再热门，如果入门门槛高、竞争强、对资源要求高，你硬冲进去，成本会非常高。普通人更要看自己能不能跨过第一道门槛。

第三，看长期回报。

不要只看第一份工作的工资，还要看3年后有没有成长空间，能力能不能复用，行业是不是持续需要人。

举个例子，有个普通本科同学一开始想做互联网运营，因为觉得热门。但他没有相关实习，城市机会也少。后来我们重新梳理他的优势，发现他表达能力强、抗压不错、本地资源熟，最后转向教育行业销售和运营结合的岗位，反而更容易起步。

所以，职业方向不是别人说出来的，是你拿自己的筹码算出来的。

如果你现在也在纠结方向，别只问哪个行业好。你可以先把专业、城市、目标岗位写下来，再对照这3个标准看一遍。

想让我帮你初步判断，也可以评论区留言你的专业和目标方向。
```

## 8. 标签

```text
#职业规划 #大学生就业 #职场新人 #求职经验 #专业选择 #就业方向 #职场干货
```

## 9. 评论区引导

```text
你现在最纠结的职业方向是什么？可以把专业 + 城市 + 想去的行业打在评论区。
```

## 10. 私信承接话术

```text
你可以先发我3个信息：专业、所在城市、目前想去的岗位。我先帮你看一下方向是不是匹配你的筹码。
```

## 11. 图片结构：6图版本

### 图1：封面图

用途：制造点击。

图中文字：

```text
别再盲目追热门专业
选方向前先看这3点
```

画面建议：

```text
干净书桌场景，笔记本电脑、便签纸、职业规划关键词，真实小红书干货风，画面明亮，标题醒目。
```

生成提示词：

```text
小红书干货封面图，主题是职业规划和方向选择，真实明亮的书桌场景，笔记本电脑、便签纸、咖啡、简洁背景，画面上方留出标题区域，整体风格清爽、真实、有收藏感，不要夸张商业海报，不要复杂背景，不要乱码文字。
```

### 图2：痛点图

用途：让用户看到自己的问题。

图中文字：

```text
为什么越听建议越迷茫？
因为你缺的不是信息，是判断标准
```

画面建议：

```text
一个人在电脑前查看很多网页和笔记，表情思考但不焦虑，突出信息过载。
```

生成提示词：

```text
真实生活方式图片，一个年轻人在电脑前查职业建议，桌面有笔记和资料，表现信息很多但难以判断的状态，画面自然，小红书经验分享风格，避免夸张焦虑表情，避免AI感。
```

### 图3：方法图

用途：输出3个判断标准。

图中文字：

```text
选方向先看3件事
1. 你的筹码
2. 行业门槛
3. 长期回报
```

画面建议：

```text
知识卡片风，结构清晰，适合收藏。
```

生成提示词：

```text
小红书知识卡片，白色背景，清晰三点结构，职业规划主题，信息图风格，干净、专业、有收藏价值，预留清晰文字区域，避免复杂装饰。
```

### 图4：筹码解释图

用途：解释“筹码”不是抽象概念。

图中文字：

```text
你的筹码包括：
学历 / 专业 / 城市 / 实习 / 表达 / 资源 / 抗压
```

画面建议：

```text
便签墙或清单风，每个筹码作为一个标签。
```

生成提示词：

```text
清单式小红书配图，主题是个人职业筹码，便签纸和标签元素，展示学历、专业、城市、实习、表达、资源、抗压等关键词，画面温和真实，适合收藏。
```

### 图5：案例图

用途：增强信任。

图中文字：

```text
案例：普通本科同学
盲目追热门 → 重新匹配筹码 → 找到更适合的起步方向
```

画面建议：

```text
前后对比卡片，一侧迷茫，一侧清晰路径。
```

生成提示词：

```text
小红书案例拆解配图，前后对比结构，左侧表现盲目追热门，右侧表现重新梳理方向，职业规划主题，真实可信，清爽知识风，不要夸张，不要广告感。
```

### 图6：行动引导图

用途：引导评论和私信。

图中文字：

```text
不知道怎么选？
评论区留下：专业 + 城市 + 目标方向
```

画面建议：

```text
温和引导卡片，留白明显，适合最后一张。
```

生成提示词：

```text
小红书结尾行动引导图，职业规划主题，画面简洁温和，留白充足，有评论互动氛围，适合图文笔记最后一张，真实不营销。
```

## 14. 风险提醒

系统应在发布包中提示：

```text
请发布前人工检查图片文字是否清晰、是否存在错别字或乱码。
请确认案例表达不涉及真实个人隐私。
请避免使用绝对化承诺，例如“保证就业”“一定拿offer”。
如涉及产品功效、医疗、金融、教育结果，请进行人工合规审核。
```

## 15. P0验收标准

- 发布包包含标题、正文、标签、评论区引导、私信话术。
- 发布包包含封面和3-8张配图。
- 每张图片有用途、图中文字和生成提示词。
- 用户可以重新生成单张图片。
- 用户可以复制文案和标签。
- 用户可以下载图片包。
- 发布包不包含自动发布能力。
