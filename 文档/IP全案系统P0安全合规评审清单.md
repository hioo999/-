# IP全案系统P0安全合规评审清单

## 1. 文档目标

本文档用于P0阶段安全和合规评审，确保公众号授权、图片模型密钥、用户素材、AI生成内容和平台发布包满足基本安全与合规要求。

## 2. 评审范围

P0安全合规评审覆盖：

- 公众号AppID/AppSecret。
- 图片模型API Key。
- access_token缓存。
- 用户上传素材。
- AI生成图片。
- AI生成文案。
- 公众号草稿同步。
- 小红书发布包。
- 短视频脚本和提词器稿。
- 朋友圈私域话术。
- 日志脱敏。

## 7. AI文案合规清单

| 风险类型 | 检查要求 |
|---|---|
| 广告法极限词 | 避免“最、第一、唯一、保证”等绝对表达 |
| 教育承诺 | 避免“保证就业、一定上岸、保offer”等结果承诺 |
| 医疗健康 | 避免未经证明的功效承诺 |
| 金融投资 | 避免收益承诺和投资建议 |
| 虚假案例 | 案例表达不得伪造真实身份和结果 |
| 平台引流 | 避免明显违规导流表达 |
| 隐私风险 | 不暴露真实客户个人信息 |
| 版权风险 | 不抄袭已有文章或笔记 |

## 8. 平台专项合规

### 8.1 公众号

- 标题不得严重夸大。
- 摘要不得制造虚假结果。
- 正文不得使用违规引流话术。
- 文末转化区要自然克制。
- 草稿同步后必须提示人工检查。

### 8.2 小红书

- 避免过度营销和硬广口吻。
- 标签不得堆砌无关热词。
- 图片文字必须人工检查。
- 种草内容要避免虚假体验。
- 私信引导要避免违规导流表达。

### 8.3 抖音/视频号

- 钩子不能制造虚假恐吓。
- 观点不能恶意攻击群体。
- 口播不得承诺确定结果。
- 私域承接话术要合规。

### 8.4 朋友圈

- 不生成刷屏式硬广。
- 不伪造客户反馈。
- 不夸大成交或服务结果。
- 私聊话术避免强迫转化。

## 11. 前端提示文案要求

必须出现的安全提示：

```text
AppSecret仅用于同步公众号草稿，系统将加密保存，不会明文展示。
```

```text
草稿同步成功后，请前往公众号后台检查排版、图片和链接后再发布。
```

```text
AI生成内容仅供参考，发布前请人工检查事实、版权和平台规则风险。
```

## 12. 安全合规验收标准

- 密钥不明文存储和返回。
- 公众号只同步草稿，不直接群发。
- AI内容有风险提醒。
- 图片生成有主体一致性和版权风险提示。
- 小红书发布包不包含自动发布能力。
- 短视频提词稿不改提词器功能。
- 日志脱敏通过。
- 安全/合规确认后方可进入P0验收。
