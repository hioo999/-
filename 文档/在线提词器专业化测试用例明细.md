# 在线提词器专业化测试用例明细

## 1. 文档目标

本文档用于指导测试工程师验证在线提词器专业化 V0.1 是否满足可用录制闭环要求。

V0.1 测试重点：

- 脚本可以从空白入口、AI脚本、短视频发布包进入提词器。
- 用户可以编辑、预览、播放、暂停、调速、跳段。
- 全屏模式稳定，退出后不丢位置。
- 快捷键可用且不影响文本输入。
- 本地草稿可恢复。
- 长稿、移动端、Safari 等关键场景可用。

## 2. 测试环境准备

### 2.1 浏览器

- Chrome 最新版。
- Safari 最新版。
- Edge 最新版。
- iPad Safari。
- 手机 Safari 或 Chrome。

### 2.2 测试数据

短脚本：

```text
很多人职业选错，不是因为不努力。
而是一开始算法就错了。
你不能只问哪个行业热门，你要问自己有什么筹码。
```

长脚本：

```text
准备一篇 30000 字以内、多段落、有空行、有标题、有停顿标记的脚本。
```

特殊脚本：

```text
包含中文、英文、数字、标点、Emoji、Markdown标题、[停顿]、空行、超长段落。
```

### 2.3 前置条件

- 可访问 `/teleprompter`。
- 存在可用 `scriptId`。
- 存在可用 `video-packageId`。
- 浏览器允许 localStorage。
- 如测试云端草稿，需登录测试账号。

## 3. 入口测试用例

### TC-TP-ENTRY-001 空白入口进入提词器

步骤：

```text
访问 /teleprompter
观察页面展示
```

预期：

- 页面进入空状态。

- 不展示播放控制栏。


预期：

- 页面进入编辑态。

步骤：


预期：

- 页面进入编辑态。
- 口播脚本完整带入。

## 19. V0.1 通过标准

必须全部满足：

- 空白入口、AI脚本入口、短视频发布包入口均可进入。
- 脚本可编辑、可预览、可开始提词。
- 播放、暂停、调速、跳段稳定。
- 全屏进入和退出不丢位置。
- 快捷键可用且不影响文本输入。
- 刷新后可恢复本地草稿。
- 30000字以内长稿可完成基础播放。
- 桌面、平板、手机可完成基础提词。
- 关键异常有明确提示。

## 20. V0.1 不通过条件

任一出现则不通过：

- 页面无法进入提词器。
- 正文为空仍可开始提词。
- 播放暂停出现明显失控。
- 全屏退出后脚本或位置丢失。
- 输入框按 Space 会触发播放控制。
- localStorage 失败导致页面不可用。
- 长稿播放明显卡死。
- 移动端无法完成播放和暂停。
- XSS 文本被执行。
