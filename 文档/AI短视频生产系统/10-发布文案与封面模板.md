# 发布文案与封面模板

AI视频生成后，应继续生成平台发布物料，让短视频进入 IP 内容闭环。

## 通用发布物料提示词

```text
请根据以下短视频内容，生成适合 {{平台}} 发布的物料。

视频主题：{{视频主题}}
视频类型：{{视频类型}}
目标受众：{{目标受众}}
核心卖点/观点：{{核心卖点}}{{核心观点}}
IP人设/品牌调性：{{IP人设}}{{品牌调性}}

请输出：
1. 5个标题。
2. 3个封面文案。
3. 1版正式发布文案。
4. 1版更口语化的发布文案。
5. 10个话题标签。
6. 3条评论区引导。
7. 1条私域或转化引导。

要求：
1. 标题要有钩子，但不要标题党。
2. 文案要符合平台语气。
3. 不要夸大承诺，不要虚假营销。
4. 保持 IP 人设和品牌调性一致。
```

## 小红书发布文案

```text
请为这条视频生成小红书发布文案。要求有生活感、真实体验、轻种草，不要硬广。

输出：
【标题】
【正文】
【封面文案】
【话题标签】
【评论区引导】
```

## 抖音发布文案

```text
请为这条视频生成抖音发布文案。要求前半句有钩子，节奏短，适合视频标题和评论互动。

输出：
【标题】
【视频描述】
【封面文案】
【话题标签】
【置顶评论】
```

