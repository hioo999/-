# 视频模型适配规则

同一套分镜和脚本，应根据视频模型特点改写最终提示词。

## 即梦2.0

- 适合中文复杂描述。
- 可以保留较完整的镜头脚本。
- 要明确“参考九宫格从左到右、从上到下”。
- 要反复强调主体一致性、禁止改字、禁止变形。

提示词重点：

```text
中文详细动态脚本 + 镜头编号 + 主体一致性 + 禁止事项
```

## 可灵

- 重视动作连续性。
- 动作轨迹要写清楚。
- 不要同时塞太多复杂动作。
- 每个镜头尽量只承担一个主动作。

提示词重点：

```text
动作连续性 + 运动方向 + 主体一致性 + 镜头衔接
```

## Runway

- 英文提示词效果通常更稳定。
- 适合电影镜头语言和视觉风格描述。
- 文字和品牌包装要尽量依赖参考图，不要让模型重写。

提示词重点：

```text
cinematic camera movement + product consistency + lighting + shot sequence
```

## 海螺

- 适合中文短视频语境。
- 动作和情绪要明确。
- 适合生活方式、宠物、人物剧情类内容。

提示词重点：

```text
短视频节奏 + 情绪变化 + 动作清晰 + 平台审美
```

## Pika

- 适合短动作和风格化画面。
- 不宜一次生成过长复杂视频。
- 可以把15秒拆成多个短片段。

提示词重点：

```text
单镜头动作 + 风格化视觉 + 简短明确的运动描述
```

## 适配原则

- 分镜先统一，最终提示词再适配模型。
- 产品类优先强调包装和文字一致性。
- 宠物类优先强调品种、毛色、动作自然。
- 人物类优先强调脸型、人设、服装、表情和口型。
- 复杂视频优先拆镜头生成，再合成剪辑。
