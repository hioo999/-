# 人物IP短片提示词模板

适用于个人IP、创始人IP、专家IP、虚拟人、数字分身、剧情人设。

## 人物一致性锚点

```text
始终保持人物脸型、五官、发型、发色、肤色、体型、服装、配饰、年龄感、气质和人设表达方式与参考图完全一致，不得换脸、改年龄、改服装风格、改人设、面部扭曲或出现多余手指。
```

## 人物IP角色设定图提示词

```text
请基于上传图片中的人物 IP「{{IP名称}}」，生成一张角色一致性设定图。

画面包含：正面、侧面、背面、半身姿态四个视角。

一致性要求：
1. 人物脸型、五官、发型、发色、肤色、体型、服装、配饰必须与上传图片保持一致。
2. 不得改变人物年龄感、气质、人设风格。
3. 保持统一光源、统一背景、统一写实、半写实或动画风格。
4. 适合作为后续人物 IP 短视频的角色参考图。

请同时提炼角色一致性锚点：
人物脸部特征：
发型服装特征：
气质关键词：
禁止改变项：
```

## 人物IP九宫格剧情分镜提示词

```text
请为人物 IP「{{IP名称}}」设计一组 {{画面比例}} 短视频剧情分镜图，以 3×3 网格呈现9个无边界满屏超清镜头。

IP人设：{{IP人设}}
视频主题：{{视频主题}}
核心观点/情绪：{{核心观点}}
目标受众：{{目标受众}}
情绪基调：{{情绪基调}}
平台：{{平台}}

叙事结构：
第1格：场景建立，交代人物所处环境。
第2格：人物登场，建立人设气质。
第3格：人物面部或动作特写，强化情绪。
第4格：问题出现或冲突建立。
第5格：人物做出判断、表达观点或采取行动。
第6格：剧情或情绪高潮。
第7格：人物反应或观众共鸣点。
第8格：观点落地或情绪释放。
第9格：人物定格结尾，形成 IP 记忆点。

画面要求：
1. 全程保持人物面部、发型、服装、体型、气质一致。
2. 镜头有电影短片感，包含近景、中景、全景、过肩镜头、低角度、推近等。
3. 画面要服务于 IP 人设，不要变成普通广告片。
4. 每一格都要有明确的剧情功能。
```
