# 空间探店提示词模板

适用于餐厅、茶馆、民宿、展厅、办公室、线下门店、展览、商业空间。

## 空间一致性锚点

```text
始终保持空间结构、入口位置、主视觉区域、材质、灯光、品牌气质和动线逻辑一致，不得让空间前后矛盾，不得生成错误招牌和无关文字。
```

## 空间九宫格分镜模板

```text
请为「{{空间名称}}」生成一组 {{画面比例}} 的空间探店宣传九宫格分镜。

空间类型：{{空间类型}}
品牌/门店名称：{{品牌名称}}
核心卖点：{{核心卖点}}
目标人群：{{目标受众}}
情绪基调：{{情绪基调}}
平台：{{平台}}

叙事结构：
第1格：外立面或入口，建立第一印象。
第2格：推门进入或空间转场，制造探索感。
第3格：空间全景，展示整体设计。
第4格：材质、灯光、陈设细节特写。
第5格：核心体验区，如餐桌、茶席、展台、房间、工位。
第6格：人物在空间中的自然互动。
第7格：服务、产品或体验瞬间。
第8格：氛围高潮，如夜景灯光、人群热度、安静独处。
第9格：品牌或空间记忆点收尾。

画面要求：
1. 空间结构要合理，不能前后矛盾。
2. 风格统一，光线高级，动线清晰。
3. 不要生成大段错误文字，不要乱加招牌。
4. 适合用于后续生成探店短视频。
```

## 空间视频脚本模板

```text
你是商业空间宣传片导演。请根据空间九宫格分镜，为「{{空间名称}}」写一个 {{视频时长}} 的动态视频脚本。

要求：
1. 体现从外到内、从整体到细节、从环境到体验的空间动线。
2. 加入推门、走入、环绕、推近、俯拍、跟拍等运镜。
3. 声音包括环境声、脚步声、开门声、人声氛围、背景音乐。
4. 节奏高级，有探店感和沉浸感。

输出格式：
【视频标题】
【空间定位】
【镜头脚本】
【声音设计】
【字幕建议】
【禁止事项】
```

## 空间最终视频提示词

```text
请基于空间九宫格分镜和动态脚本，生成一条 {{视频时长}} 的空间探店宣传短视频。

【空间一致性】
保持空间动线、入口、核心区域、材质、灯光和品牌气质一致，不要让空间前后矛盾。

【参考图说明】
九宫格为9个连续镜头关键帧，请按照从左到右、从上到下的顺序执行。

【画面比例】
{{画面比例}}

【动态脚本】
{{粘贴动态脚本}}

【声音氛围】
环境声、脚步声、开门声、轻微人声、空间混响和高级背景音乐。

【禁止事项】
不得乱生成品牌招牌，不得出现错误文字，不得让空间结构前后不一致，不得过度拥挤。
```
