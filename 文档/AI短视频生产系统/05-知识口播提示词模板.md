# 知识口播提示词模板

适用于教育、商业、职场、法律、心理、财经、医学科普、AI教程等专家型IP。

## 知识口播脚本模板

```text
请为专家型 IP「{{IP名称}}」生成一条 {{视频时长}} 的知识口播短视频脚本。

账号定位：{{账号定位}}
目标受众：{{目标受众}}
主题：{{视频主题}}
核心观点：{{核心观点}}
平台：{{平台}}
表达风格：专业、直接、有判断、有案例、不空泛

结构要求：
1. 前3秒钩子：用反常识、痛点、结果或冲突开场。
2. 中段解释：用2-3个要点讲清楚。
3. 案例/类比：用一个生活化例子降低理解成本。
4. 结尾：给出明确行动建议或金句收束。

输出格式：
【标题】
【3秒钩子】
【完整口播稿】
【B-roll画面建议】
【字幕重点】
【封面标题】
【评论区引导】
```

## 知识口播九宫格B-roll分镜模板

```text
请为知识口播视频「{{视频主题}}」设计一组 {{画面比例}} 九宫格 B-roll 分镜图，用于辅助口播画面。

IP人设：{{IP人设}}
核心观点：{{核心观点}}
目标受众：{{目标受众}}
平台：{{平台}}

分镜结构：
第1格：强钩子画面，体现问题或冲突。
第2格：人物口播近景，建立专业感。
第3格：痛点场景可视化。
第4格：第一个观点的视觉隐喻。
第5格：第二个观点的案例画面。
第6格：数据、文件、屏幕、白板等信息画面。
第7格：用户改变前后的对比。
第8格：解决方案落地画面。
第9格：人物看向镜头，形成结尾记忆点。

画面要求：
1. 适合短视频平台，信息清晰，视觉简洁。
2. 人物形象、服装、风格保持一致。
3. 不要生成大段文字，画面中的文字尽量少。
4. 画面服务于观点表达，不要过度电影化。
```

## 知识口播最终提示词

```text
请基于口播脚本和B-roll分镜，生成一条 {{视频时长}} 的知识口播短视频。

【人物一致性】
保持人物形象、服装、发型、气质与参考图一致，口型自然，表情专业可信。

【内容要求】
前3秒必须有清晰钩子，中段观点明确，结尾给出行动建议或金句。

【画面比例】
{{画面比例}}

【动态脚本】
{{粘贴口播脚本和B-roll脚本}}

【字幕要求】
字幕短句化，突出关键词，不要满屏文字，不要出现错字。

【禁止事项】
不得改变人物身份，不得生成错误大段文字，不得让画面与观点无关，不得出现虚假数据。
```
