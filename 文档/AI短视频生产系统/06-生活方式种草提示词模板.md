# 生活方式种草提示词模板

适用于美妆、穿搭、家居、旅行、咖啡、香氛、母婴、运动、健康食品等内容。

## 生活方式九宫格模板

```text
请围绕「{{主体名称}}」生成一组 {{画面比例}} 生活方式种草短视频九宫格分镜。

产品/主体：{{主体名称}}
目标人群：{{目标受众}}
使用场景：{{使用场景}}
情绪基调：松弛、自然、真实、有审美、有生活质感
平台：{{平台}}

叙事结构：
第1格：生活痛点或氛围开场。
第2格：主体自然出现，不要硬广。
第3格：细节特写，突出质感。
第4格：真实使用动作。
第5格：使用中的感受表达。
第6格：场景升级，体现生活方式。
第7格：对比变化，如使用前后、心情变化、空间变化。
第8格：主体与人物或环境融合。
第9格：自然收尾，留下记忆点。

画面要求：
1. 不要过度广告化，要像真实生活中拍到的高级 Vlog。
2. 光线自然，构图有审美，细节真实。
3. 如果出现产品，必须保持产品外观一致。
4. 适合小红书、抖音种草风格。
```

## 生活方式视频脚本模板

```text
你是生活方式短视频导演。请根据九宫格分镜，为「{{主体名称}}」写一个 {{视频时长}} 的种草短视频动态脚本。

要求：
1. 节奏自然，不要硬广。
2. 每个镜头都要有动作和情绪变化。
3. 运镜以手持、推近、跟拍、自然切换为主。
4. 加入适合平台的旁白或字幕文案。
5. 结尾要形成轻种草，不要强销售。

输出格式：
【视频标题】
【开场钩子】
【镜头脚本】
【旁白文案】
【字幕重点】
【结尾引导】
【禁止事项】
```

## 生活方式最终视频提示词

```text
请基于九宫格分镜和动态脚本，生成一条 {{视频时长}} 的生活方式种草短视频。

【主体一致性】
如果画面中出现「{{主体名称}}」，必须保持外观、颜色、包装、比例和质感与参考图一致。

【风格要求】
真实、松弛、自然、有审美，像真实生活记录，不要像硬广。

【画面比例】
{{画面比例}}

【动态脚本】
{{粘贴动态脚本}}

【声音氛围】
自然环境声、轻音乐、轻微生活动作声，可加入简短旁白。

【禁止事项】
不得强行堆砌卖点，不得生成错误文字，不得破坏主体外观，不得过度商业化。
```
