# 通用短视频提示词模板

本模板适用于尚未确定具体场景时的通用工作流。使用时先判断主体类型，再调用对应专项模板。

## 变量表

```text
{{上传图片}}：用户上传的原始图片
{{主体类型}}：产品 / 宠物 / 人物IP / 知识口播 / 生活方式 / 空间探店
{{主体名称}}：具体名称
{{品牌名称}}：品牌名，没有则写“无”
{{视频类型}}：TVC广告 / Vlog / 剧情短片 / 种草视频 / 口播视频 / 探店视频
{{目标受众}}：谁看
{{核心卖点}}：产品或服务要表达的重点
{{核心观点}}：知识口播或人物IP要表达的观点
{{视频主题}}：本条视频主题
{{情绪基调}}：高级 / 温暖 / 治愈 / 专业 / 轻松 / 潮流 / 松弛
{{画面比例}}：16:9 / 9:16 / 1:1
{{视频时长}}：默认15秒
{{平台}}：抖音 / 小红书 / 视频号 / B站 / 快手
{{模型}}：即梦2.0 / 可灵 / Runway / 海螺 / Pika
```

## 信息采集提示词

```text
请先根据我上传的图片和描述，判断这是哪类短视频生产任务：产品TVC、宠物Vlog、人物IP、知识口播、生活方式种草、空间探店。

如果信息不足，请只问最关键的5个问题：
1. 视频用于哪个平台？
2. 希望横版还是竖版？
3. 视频时长是否为15秒？
4. 想表达的核心卖点、观点或情绪是什么？
5. 希望整体风格是高级、治愈、专业、松弛、潮流还是温暖？

不要一次询问过多细节。拿到答案后，直接进入短视频提示词生产链路。
```

## 通用主体清理提示词

```text
针对上传图片 {{上传图片}}，请识别图片中的核心主体「{{主体名称}}」。

请清除图片中除核心主体以外的干扰元素，包括背景杂物、无关文字、标注、水印、贴纸、噪点和多余装饰。

核心主体必须保持完全不变：外形、比例、颜色、材质、纹理、结构、关键细节全部与原图一致，不得重绘、不得改字、不得变形、不得新增任何文字或标识。

输出为干净背景、高清写实风格、适合作为后续短视频生成参考图的主体图片。
```

## 通用九宫格分镜提示词

```text
请围绕「{{主体名称}}」生成一组 {{画面比例}} 的九宫格短视频分镜图，以 3×3 网格呈现9个无边界满屏超清镜头。

视频类型：{{视频类型}}
视频主题：{{视频主题}}
目标受众：{{目标受众}}
核心表达：{{核心卖点}}{{核心观点}}
情绪基调：{{情绪基调}}
平台：{{平台}}

分镜结构：
第1格：开场环境，建立场景和情绪。
第2格：主体登场，建立识别。
第3格：细节特写，强化记忆点。
第4格：动作开始，进入叙事。
第5格：核心卖点、核心观点或核心情绪。
第6格：视觉高潮或剧情高潮。
第7格：体验、反应或共鸣。
第8格：情绪释放或结果呈现。
第9格：品牌、IP或故事收尾。

画面要求：
1. 每一格都必须是可用于视频生成的关键帧。
2. 镜头之间要有连续叙事关系，不要变成无关海报拼图。
3. 主体必须全程保持一致，不得变形、换主体或出现错误文字。
4. 镜头语言包含特写、中景、全景、俯拍、仰拍、跟拍、推近等变化。
5. 整体风格符合 {{平台}} 的优质短视频审美。
```

## 通用动态视频脚本提示词

```text
你是专业 AI 短视频导演和 AI 视频提示词专家。请根据九宫格分镜图，为「{{主体名称}}」写一个 {{视频时长}} 的动态视频脚本。

要求：
1. 每个镜头必须对应九宫格中的一格。
2. 输出9个镜头，每个镜头包含时间、画面、动作、运镜、声音、转场。
3. 必须是动态描述，不要只写静态画面。
4. 主体必须全程保持一致。
5. 节奏适合 {{平台}}，并适配 {{模型}} 视频生成模型。

输出格式：

【视频标题】
【视频类型】
【主体一致性要求】
【镜头脚本】

镜头1：0-1.5s
画面：
动作：
运镜：
声音：
转场：

直到镜头9。

【整体风格】
【禁止事项】
```

## 通用最终视频生成提示词

```text
请基于上传的九宫格分镜图和以下动态脚本，生成一条 {{视频时长}} 的 {{视频类型}}。

【主体一致性】
始终保持「{{主体名称}}」的外形、颜色、结构、比例、材质、关键细节与参考图完全一致，不得变形、不得换主体、不得新增无关文字、不得出现水印。

【参考图片说明】
上传的九宫格图片为9个连续镜头关键帧，每一格对应一个视频镜头，请按照从左到右、从上到下的顺序执行。

【画面比例】
{{画面比例}}

【视频时长】
{{视频时长}}

【动态脚本】
{{粘贴15秒视频脚本}}

【运镜要求】
镜头运动自然流畅，包含推近、跟拍、微距、轻微环绕、景深变化和自然转场。不得出现突然跳变和不合理运动。

【声音氛围】
根据视频类型加入背景音乐、环境声、动作声和必要的人声或旁白，声音干净，与画面节奏匹配。

【禁止事项】
不得改变主体外观，不得出现错字，不得新增水印，不得出现畸变、多余肢体、主体漂移、镜头断裂和风格突变。
```
