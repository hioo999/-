# 前端自动识别接入说明

本说明用于把 AI短视频生产系统接入前端，实现“用户上传素材/输入需求后，系统自动识别场景并返回完整工作流”。

## 后端接口

### 获取支持的短视频场景

```http
GET /api/short-video/intents
```

返回内容：

```json
{
  "code": 0,
  "data": [
    {
      "key": "product_tvc",
      "label": "产品TVC",
      "command": "/产品TVC",
      "template_doc": "文档/AI短视频生产系统/02-产品TVC提示词模板.md",
      "keywords": ["产品", "包装", "饮料"],
      "steps": ["asset_profile", "consistency", "storyboard"]
    }
  ]
}
```

### 自动识别并生成工作流

```http
POST /api/short-video/workflow
```

请求示例：

```json
{
  "user_input": "我上传的是一款无糖杏仁甘露饮料，做15秒小红书短视频",
  "requested_intent": "auto",
  "subject_name": "无糖杏仁甘露",
  "platform": "小红书",
  "aspect_ratio": "9:16",
  "duration": "15秒",
  "model": "即梦2.0",
  "style": "高级清爽",
  "target_audience": "关注健康饮品的年轻女性",
  "core_message": "无糖、东方包装、高级清爽"
}
```

返回内容：

```json
{
  "code": 0,
  "data": {
    "intent": {
      "intent": "product_tvc",
      "label": "产品TVC",
      "confidence": 0.95,
      "matched_keywords": ["饮料", "产品"],
      "source": "keyword"
    },
    "workflow": {
      "key": "product_tvc",
      "label": "产品TVC",
      "recommended_command": "/产品TVC",
      "template_doc": "文档/AI短视频生产系统/02-产品TVC提示词模板.md"
    },
    "steps": [
      {
        "key": "asset_profile",
        "label": "IP资产建档",
        "description": "沉淀主体资产档案，供长期复用。",
        "prompt": "可直接复制使用的提示词"
      }
    ],
    "next_actions": []
  }
}
```

## 前端 API 函数

已在 `frontend/src/api/index.ts` 中新增：

```ts
listShortVideoIntents()
buildShortVideoWorkflow(params)
```

## 推荐前端交互

```text
用户上传素材/输入需求
↓
调用 buildShortVideoWorkflow
↓
展示识别结果：产品TVC / 宠物Vlog / 人物IP / 知识口播 / 生活方式 / 空间探店
↓
用户可手动切换场景
↓
展示工作流步骤卡片
↓
每个步骤支持复制提示词、重新生成、进入下一步
```

## 页面模块建议

- 识别结果卡片：场景、置信度、命中的关键词、推荐命令。
- 参数表单：主体名称、平台、比例、时长、模型、风格、目标受众、核心表达。
- 工作流步骤卡片：资产建档、一致性锚点、四视图、九宫格、脚本、最终视频提示词、发布文案、质检。
- 快捷操作：复制提示词、发送到图像模型、发送到视频模型、保存项目归档。

## 当前实现边界

- 当前后端识别是确定性关键词路由，不依赖 AI Key。
- 识别结果稳定、可解释，但复杂语义理解有限。
- 后续可以在不改变接口结构的前提下，增加大模型分类作为增强层。
