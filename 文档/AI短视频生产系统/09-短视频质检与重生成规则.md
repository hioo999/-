# 短视频质检与重生成规则

## 质检清单

- 主体一致性：是否变形、换脸、改包装、改毛色。
- 镜头连续性：动作是否顺畅，前后是否接得上。
- 品牌一致性：颜色、标识、气质是否统一。
- 平台适配：比例、节奏、前3秒钩子是否合适。
- 商业表达：卖点是否清楚，是否有购买理由。
- 内容表达：观点是否清楚，是否符合IP人设。
- 画面质量：是否畸变、虚焦、文字错误、水印。
- 声音表现：音乐、环境声、动作声是否匹配。

## 常见问题与修正

产品变形：

```text
请保持产品包装、瓶型、标签、文字、图案、颜色和比例与参考图完全一致，仅修正变形问题，不要改变镜头结构和画面风格。
```

宠物变脸或变品种：

```text
请保持宠物品种、毛色、花纹、眼睛、耳朵、体型和尾巴与参考图完全一致，仅修正宠物外观漂移问题，不要改变动作和场景。
```

人物换脸或服装变化：

```text
请保持人物脸型、五官、发型、服装、年龄感和气质与参考图完全一致，仅修正人物一致性问题，不要改变台词和镜头节奏。
```

镜头不连续：

```text
请保持原九宫格分镜结构不变，增强第{{前镜头}}镜头到第{{后镜头}}镜头之间的动作衔接，让主体运动方向、姿态和场景逻辑连续。
```

文字错误：

```text
请不要生成新的文字，不要重写包装文字或招牌文字。所有文字内容必须依赖参考图，不得出现错字、乱码、水印或额外标识。
```

## 局部重生成模板

```text
请保持原九宫格分镜结构不变，仅修正第{{镜头编号}}镜头的问题：{{问题描述}}。

必须保持：
1. 主体一致。
2. 镜头功能不变。
3. 整体风格不变。
4. 其他镜头不变。

禁止：
1. 改变主体外观。
2. 改变品牌文字。
3. 改变人物或宠物身份。
4. 改变整体叙事顺序。
```
