# 产品TVC提示词模板

适用于酒水、饮料、香水、护肤品、食品、茶叶、电子产品、文创产品等商品短视频。

## 产品一致性锚点

```text
始终保持产品外形、包装结构、瓶盖/罐口、标签位置、品牌标识、包装文字、图案、颜色、材质、比例、反光和纹理与参考图完全一致，不得改字、加字、改品牌、改包装、变形或生成多余产品。
```

## 产品主体清理提示词

```text
针对上传图片 {{上传图片}}，请识别图片中的主体产品「{{主体名称}}」。

请清除图片中除主体产品以外的所有干扰元素，包括背景杂物、无关文字、标注、水印、贴纸、阴影噪点和多余装饰。

主体产品必须保持完全不变：产品外形、包装比例、瓶身/罐身结构、标签位置、文字内容、品牌标识、颜色、材质、纹理、光泽、图案细节全部与原图一致，不得重绘、不得改字、不得变形、不得新增任何文字。

输出为纯白背景、写实摄影风格、高清产品图。
```

## 产品四视图提示词

```text
这是我的产品「{{主体名称}}」。请基于上传图片生成一张产品四视图设定图。

画面包含：正面视图、侧面视图、背面视图、顶部视图。

核心要求：
1. 产品外形、尺寸比例、包装结构完全一致。
2. 瓶盖/罐口/标签/图案/文字/材质/颜色必须与上传图片保持一致。
3. 不得改变品牌标识，不得新增文字，不得出现错字。
4. 四个视角都使用统一光源、统一白色背景、统一写实摄影风格。
5. 画面干净高级，适合作为后续视频生成的产品一致性参考图。

请先根据上传图片判断产品的关键一致性锚点，再生成四视图。
```

## 产品九宫格分镜提示词

```text
请为产品「{{主体名称}}」生成一组 {{画面比例}} 高级 TVC 广告九宫格分镜图，以 3×3 网格呈现9个无边界满屏超清镜头。

视频主题：{{视频主题}}
核心卖点：{{核心卖点}}
目标受众：{{目标受众}}
情绪基调：{{情绪基调}}
平台：{{平台}}

叙事结构：
第1格：产品所在环境的高级氛围建立。
第2格：产品首次登场，突出轮廓和整体质感。
第3格：产品局部特写，突出材质、包装细节或核心图案。
第4格：使用场景或手部交互，体现真实使用感。
第5格：核心卖点视觉化表达，如清爽、能量、滋养、醇厚、科技感等。
第6格：视觉高潮镜头，使用强光影、慢动作、液体、粒子、烟雾或反射等动态感构图。
第7格：情绪价值镜头，体现用户体验、生活方式或品牌态度。
第8格：产品回到主视觉中心，形成记忆点。
第9格：品牌收尾定格，产品英雄镜头，高级商业广告质感。

画面要求：
1. 全程保持产品造型、包装文字、图案、颜色、材质与参考图100%一致。
2. 不得改变产品结构，不得出现错字，不得新增虚假品牌信息。
3. 镜头语言包含特写、中景、全景、俯拍、仰拍、微距、推近、环绕等电影化构图。
4. 光影层次丰富，商业摄影质感，高级、精致、有购买欲。
5. 九宫格每一格都应像可直接用于视频生成的关键帧。
```

```text
要求：

2. 输出9个镜头，每个镜头包含时间、画面、动作、运镜、声音、转场。
3. 必须是动态描述，不要写静态图片描述。
4. 全程保持产品包装、文字、图案、颜色、材质、比例完全一致。
5. 风格为高级商业广告、电影级光影、强节奏、强质感。

输出格式：

【视频标题】
【视频类型】
【主体一致性要求】
【镜头脚本】

镜头1：0-1.5s
画面：
动作：
运镜：
声音：
转场：

直到镜头9。

【整体风格】
【禁止事项】
```

## 产品最终视频生成提示词

```text
请基于上传的产品九宫格分镜图和以下动态脚本，生成一条 {{视频时长}} 的高级产品 TVC 广告视频。

【主体一致性】
始终保持产品「{{主体名称}}」的外形、包装结构、标签文字、品牌标识、图案、颜色、材质、比例与参考图完全一致，不得改变包装，不得新增文字，不得出现错字，不得让产品变形。

【参考图说明】
上传的九宫格图片为9个连续镜头关键帧，每一格对应一个视频镜头，请按照从左到右、从上到下的顺序执行。

【画面比例】
{{画面比例}}

【视频时长】
{{视频时长}}

【动态脚本】
{{粘贴15秒视频脚本}}

【运镜要求】
电影级推近、微距特写、慢动作、轻微环绕、景深变化、光影流动，节奏高级流畅。

【声音氛围】
高级广告配乐，适当加入开盖声、液体声、环境声、低频氛围声，声音干净克制。

【禁止事项】
不得改变产品外观，不得出现错字，不得新增水印，不得出现畸变，不得出现多余产品，不得破坏产品品牌识别。
```
