# IP全案系统P0原型页面说明

## 1. 文档目标

本文档用于指导P0阶段低保真原型设计和前端页面拆分，重点说明页面区域、核心操作、状态提示和页面跳转。

P0原型原则：

- 先可用，后精致。
- 前台按产品线清晰进入。
- 底座能力隐藏在流程中，不让用户理解复杂系统结构。
- 所有AI生成结果必须可编辑、可复制、可重新生成、可保存。
- 提词器模块不改，只在短视频发布包中提供提词器导入稿。

## 2. 信息架构

P0主导航：

```text
全案首页
IP资产
选题库
公众号
小红书
短视频
朋友圈
素材库
图片生成
发布授权
```

P0暂不把“内容日历、数据复盘、团队协作、多账号矩阵”作为主入口。

## 3. 全案首页

### 页面目标

让用户快速选择当前IP，并进入四条平台产品线。

### 页面区域

| 区域 | 内容 |
|---|---|
| 顶部当前IP | 当前IP名称、IP类型、切换IP、创建IP |
| 快捷动作 | 创建IP、生成选题、写公众号、做小红书、做短视频、发朋友圈 |
| 四平台入口 | 公众号、小红书、短视频、朋友圈 |
| 待办区 | 待生成母稿、待同步公众号、待导出发布包 |
| 授权提醒 | 公众号授权状态、图片模型状态 |
| 最近内容 | 最近生成的公众号文章、小红书笔记、短视频脚本、朋友圈文案 |

### 核心按钮

- 创建IP
- 切换IP
- 生成本周选题
- 一键生成多平台内容
- 进入公众号
- 进入小红书
- 进入短视频
- 进入朋友圈

### 空状态

当没有IP时，首页只展示：

```text
创建第一个IP
导入已有资料
查看示例IP
```

### 跳转

- 创建IP → IP资产详情页
- 进入公众号 → 公众号工作台
- 进入小红书 → 小红书工作台
- 进入短视频 → 短视频工作台
- 进入朋友圈 → 朋友圈工作台

| 列表区 | IP名称、类型、行业、主平台、最近更新时间 |
| 操作区 | 编辑、设为当前IP、删除 |

### 核心按钮

- 新建IP
- 编辑
- 设为当前IP
- 删除

### 状态

- 资料完整
- 资料待补全
- 未生成策略

## 5. IP资产详情页

### 页面目标

让用户填写IP基础资料，并作为全案生成上下文。

### 页面结构

```text
基础信息
目标用户
商业目标
平台选择
表达风格
视觉风格
素材上传
禁用表达
保存并生成策略
```

### 必填字段

- IP名称
- IP类型
- 目标用户
- 商业目标
- 主平台

### 关键交互

- 选择IP类型后，表单字段动态变化。
- 保存后提示是否立即生成内容策略。
- 上传素材后自动进入素材库并绑定当前IP。

## 6. 内容策略页

### 页面目标

根据IP资产生成定位、用户画像、平台分工和转化路径。

### 页面区域

| 区域 | 内容 |
|---|---|
| 输入摘要 | 当前IP、目标用户、商业目标、主平台 |
| 生成结果 | IP定位、用户画像、核心痛点、平台分工、转化路径 |
| 操作区 | 重新生成、保存策略、生成栏目 |

### 关键交互

- 用户可以逐段编辑策略。
- 保存策略后才能进入栏目矩阵生成。
- 重新生成前提示会覆盖未保存内容。

| 操作区 | 编辑栏目、删除栏目、新增栏目、生成选题 |

### 栏目卡片字段

- 栏目名称
- 栏目定位
- 适合平台
- 内容形式
- 推荐频率
- 代表选题
- 转化动作

- 配图生成中
- 排版生成中
- 草稿同步中

## 11. 公众号排版预览页

### 页面目标

模拟公众号移动端阅读效果。

### 页面区域

| 区域 | 内容 |
|---|---|
| 模板选择 | 专业知识型、极简商务型、个人IP口语型 |
| 手机预览 | 标题、作者、摘要、正文、图片、文末区 |
| 编辑工具 | 修改标题、正文、图片、分割线、重点样式 |
| 操作区 | 保存排版、返回编辑、同步草稿 |

### 注意事项

- P0至少提供1个默认模板。
- 预览不要求百分百等同微信后台，但必须接近移动端效果。
- HTML必须兼容公众号编辑器基础能力。

## 12. 公众号草稿同步页

### 页面目标

展示公众号授权状态和草稿同步结果。

### 页面区域

| 区域 | 内容 |
|---|---|
| 授权状态 | 公众号名称、AppID、授权测试结果 |
| 同步检查 | 标题、摘要、封面、HTML、正文图片 |
| 同步进度 | 获取token、上传封面、生成HTML、创建草稿 |
| 结果区 | 成功提示或失败原因 |

### 错误提示

- AppID或AppSecret错误
- access_token获取失败
- IP白名单未配置
- 封面上传失败
- HTML不兼容
- 草稿创建失败

| 区域 | 内容 |
|---|---|

## 20. 全局交互规范

### 20.1 AI生成状态

所有AI生成操作必须具备：

- 生成中
- 生成成功
- 生成失败
- 重新生成
- 保存
- 复制

### 20.2 编辑规范

- 所有AI文本结果都可编辑。
- 所有图片结果都可重新生成。
- 重新生成前提示可能覆盖当前内容。
- 保存后进入对应内容状态。

### 20.3 错误提示规范

错误提示必须包含：

- 发生了什么
- 可能原因
- 用户可以怎么处理

示例：

```text
公众号草稿同步失败：服务器IP未加入公众号后台白名单。
处理建议：请进入公众号后台，开发设置中添加当前服务器IP后重试。
```

## 21. P0原型验收标准

- 用户能从首页进入四条产品线。
- 用户能创建IP并生成策略、栏目、选题、母稿。
- 用户能从母稿分别进入公众号、小红书、短视频、朋友圈。
- 公众号页面覆盖文章、封面、摘要、排版、草稿同步。
- 小红书页面覆盖文案、图片、发布包导出。
- 短视频页面覆盖抖音/视频号差异、脚本、分镜、提词器稿。
- 朋友圈页面覆盖正文、评论区、私聊承接。
- 图片生成和授权配置有独立入口。
- 提词器模块没有被纳入改造范围。
