# 在线提词器专业化 PRD V0.1

## 1. 功能名称

在线提词器专业化：面向口播录制与直播场景，支持脚本导入、提词播放、全屏展示、速度与样式调节、段落跳转、快捷键控制和直播互动暂停的专业提词工具。

---

## 2. 需求背景

IP 打造全案系统当前核心链路是：

`素材输入 -> AI 生成脚本 -> 脚本打磨 -> 提词录制/直播 -> AI 出片`

其中「提词录制/直播」是从内容生产进入实际交付的关键节点。用户即使已经生成了脚本，如果无法稳定完成录制或直播讲述，前序 AI 生成价值也无法转化为最终内容产出。

当前提词器需要优先解决以下问题：

| 问题 | 影响 |
|------|------|
| 脚本进入录制链路不顺畅 | 用户需要在外部工具复制、排版、调整格式，工作流中断 |
| 提词展示不适合录制距离 | 字号、行距、对比度不合适，影响口播稳定性 |
| 播放控制不够快 | 录制中频繁操作鼠标，容易打断表达 |
| 长稿缺少段落定位 | 重录、跳段、补录成本高 |
| 直播互动时无法临时暂停 | 主播需要回答弹幕、插入临时话术后恢复原稿 |
| 全屏与设备适配不足 | 桌面录制、平板横屏、手机竖屏体验不稳定 |

产品判断：V0.1 不追求复杂智能能力，优先跑通「脚本可导入、可播放、可控制、可恢复」的录制闭环。

## 3. 目标用户

| 用户类型 | 使用场景 | 核心诉求 |
|----------|----------|----------|
| 内容创作者 | 录制口播、知识分享、种草视频 | 快速把稿子变成可读、可录、可控的提词内容 |
| 直播达人 | 直播讲品、课程直播、活动直播 | 直播中能暂停、插话、恢复，不影响节奏 |
| 短视频团队编导 | 给主播准备脚本并协助录制 | 长稿可分段、可跳转、可重录 |
| 企业 IP 运营者 | 品牌口播、培训视频、发布会录制 | 稳定、清晰、低学习成本 |

---

## 4. 核心目标

V0.1 的核心目标是让用户完成以下最短路径：

`导入/粘贴脚本 -> 调整提词显示 -> 开始播放 -> 录制中控制 -> 完成录制`

用户完成后应获得的结果：

1. 能将 AI 生成脚本或外部文稿快速导入提词器。
2. 能根据录制距离调整字号、行距、滚动速度和主题样式。
3. 能在普通模式和全屏模式下稳定播放提词内容。
4. 能通过鼠标、键盘快捷键完成播放、暂停、调速、段落跳转。
5. 能在直播互动时暂停正文，插入临时话术后恢复原提词位置。

## 6. 范围定义

### 6.1 V0.1 必须做

| 功能 | 说明 |
|------|------|
| 脚本粘贴 | 用户可直接粘贴纯文本脚本 |
| 从 AI 脚本进入提词器 | AI 生成结果页提供「进入提词器」入口 |
| 基础编辑 | 提词前可修改脚本文字 |
| 播放/暂停 | 支持提词滚动开始、暂停、继续 |
| 速度调节 | 支持慢、中、快及细粒度调节 |
| 字号调节 | 支持小、中、大、超大字号 |
| 行距调节 | 支持紧凑、标准、宽松 |
| 主题切换 | 支持深色、浅色、高对比三种主题 |
| 全屏模式 | 支持进入和退出浏览器全屏提词 |
| 段落识别 | 根据换行识别段落并生成段落列表 |
| 段落跳转 | 点击段落或快捷键跳转到上一段/下一段 |
| 快捷键控制 | 支持播放、暂停、调速、跳段、退出全屏 |
| 自动保存草稿 | 本地保存当前脚本、设置和播放位置 |

### 6.2 V0.1 可选增强

| 功能 | 说明 |
|------|------|
| 文件导入 | 支持 txt、md，docx 可视技术成本决定是否进入 V0.1 |
| 直播互动暂停 | 暂停正文滚动，显示临时互动提示区 |
| 倒计时开始 | 点击开始后 3 秒倒计时再滚动 |
| 镜像模式 | 适配部分提词设备或反射屏 |

### 6.3 暂不做

| 功能 | 不做原因 |
|------|----------|
| 语音跟读自动同步 | 技术复杂度高，容易影响 V0.1 闭环稳定性 |
| 遥控器硬件适配 | 属于专业版能力，先用键盘快捷键覆盖 |
| 多人协作批注 | 当前不影响单人录制闭环 |
| AI 实时改稿 | 先保证提词播放稳定，再增强智能改稿 |
| 云端版本历史 | V0.1 可先本地草稿保存，团队版再升级 |

## 7. 主流程

### 7.1 从 AI 脚本进入提词器

1. 用户在 AI 生成脚本结果页点击「进入提词器」。
2. 系统将当前脚本内容带入提词器编辑区。
3. 系统自动按空行或自然段识别段落。
4. 用户检查并修改脚本。
5. 用户调整字号、行距、速度和主题。
6. 用户点击「开始提词」。
7. 系统进入播放状态，提词内容按设定速度滚动。
8. 用户可暂停、继续、调速、跳段、全屏。
9. 用户完成录制后点击「结束」。
10. 系统保留当前脚本、设置和最后播放位置。

### 7.2 从空白提词器开始

1. 用户从产品首页或工具栏进入「在线提词器」。
2. 系统展示空状态，引导用户粘贴脚本或导入文件。
3. 用户粘贴脚本。
4. 系统进行段落识别并进入编辑态。
5. 用户调整设置并开始提词。

### 7.3 直播互动暂停流程

1. 用户正在播放提词内容。
2. 直播中需要回答弹幕或临时插话。
3. 用户点击「互动暂停」或按快捷键。
4. 系统暂停正文滚动，并保留当前播放位置。
5. 页面显示临时互动提示区，可输入或展示临时话术。
6. 用户点击「恢复正文」或按快捷键。
7. 系统从暂停位置继续滚动正文。

## 9. 字段与规则

### 9.1 脚本内容

| 字段 | 规则 |
|------|------|
| scriptTitle | 默认取脚本前 20 个字，可编辑 |
| scriptContent | 必填，最多 30000 字 |
| paragraphList | 根据换行、空行或 Markdown 标题自动识别 |
| currentParagraphIndex | 当前播放段落索引 |
| currentScrollPosition | 当前滚动位置 |

### 9.2 提词设置

| 字段 | 可选值 | 默认值 |
|------|--------|--------|
| fontSize | small、medium、large、xlarge | large |
| lineHeight | compact、normal、loose | normal |
| scrollSpeed | 1-10 | 5 |
| theme | dark、light、contrast | dark |
| mirrorMode | true、false | false |
| countdownEnabled | true、false | true |
| countdownSeconds | 3、5、10 | 3 |

### 9.3 快捷键规则

| 快捷键 | 行为 |
|--------|------|
| Space | 播放/暂停 |
| ArrowUp | 降低滚动速度 |
| ArrowDown | 提高滚动速度 |
| ArrowLeft | 上一段 |
| ArrowRight | 下一段 |
| F | 进入/退出全屏 |
| Esc | 退出全屏或关闭浮层 |
| I | 互动暂停/恢复正文 |
| M | 开启/关闭镜像模式 |

冲突处理：当用户焦点位于文本输入框内时，快捷键不触发播放控制，避免影响编辑输入。

## 10. 交互状态

| 状态 | 展示 | 用户可操作 |
|------|------|------------|
| 空状态 | 引导粘贴脚本、导入文件、从 AI 脚本进入 | 粘贴、导入、返回 |
| 编辑中 | 显示编辑器和预览 | 修改脚本、调整设置、开始提词 |
| 倒计时 | 显示 3/2/1 动画或数字 | 取消开始 |
| 播放中 | 提词内容滚动，控制栏弱化 | 暂停、调速、跳段、全屏 |
| 暂停中 | 提词停止，显示暂停标识 | 继续、跳段、编辑、结束 |
| 互动暂停 | 正文停止，显示互动提示区 | 输入临时话术、恢复正文 |
| 全屏中 | 提词内容居中，控制浮层自动隐藏 | 快捷键、鼠标唤起控制 |
| 保存中 | 顶部显示保存中 | 不阻塞播放 |
| 保存失败 | 顶部显示本地保存失败提示 | 重试、继续使用 |

## 11. 异常与降级

| 场景 | 处理方式 |
|------|----------|
| 脚本为空 | 禁止开始提词，提示「请先输入脚本内容」 |
| 脚本超过字数限制 | 提示超出限制，可引导拆分脚本 |
| 文件格式不支持 | 提示支持格式，保留粘贴入口 |
| 文件解析失败 | 显示失败原因，允许重新上传或手动粘贴 |
| 浏览器不支持全屏 API | 隐藏全屏按钮，提示可使用浏览器手动全屏 |
| 本地保存失败 | 提示用户复制脚本备份，不影响当前播放 |
| 页面刷新 | 优先从本地草稿恢复脚本、设置和播放位置 |
| 快捷键冲突 | 输入框聚焦时不触发全局快捷键 |
| 移动端横竖屏切换 | 保留播放位置和当前设置，重新计算滚动区域 |
| 直播互动中误触结束 | 结束录制需二次确认 |

## 15. 小P结论

当前阶段，在线提词器不应该先做复杂的语音跟读或智能实时改稿，而应该优先完成稳定的录制闭环。

V0.1 的产品边界是：

`让用户能把脚本放进来，看得清，滚得稳，控得住，能恢复。`

只要这条链路稳定，后续 AI 出片、直播增强、语音同步和团队协作才有持续迭代价值。
