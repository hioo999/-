# 在线提词器专业化低保真原型页面说明

## 1. 文档目标

本文档用于指导在线提词器专业化 V0.1 的低保真原型设计和前端页面拆分，重点说明页面区域、核心操作、状态提示和页面跳转。

V0.1 原型原则：

- 先稳定录制闭环，后智能增强。
- 录制中高频操作必须一眼可见。
- 全屏模式减少干扰，不遮挡正文。
- 所有脚本内容必须可编辑、可复制、可恢复。
- 桌面优先，同时兼顾平板横屏和手机竖屏。

## 2. 信息架构

提词器主入口：

```text
全案首页
短视频工作台
AI脚本生成结果页
在线提词器
```

提词器页面结构：

```text
提词器空状态
提词器编辑态
提词器播放态
提词器全屏态
直播互动暂停态
```

V0.1 暂不把“语音跟读、遥控器硬件、多端协作、云端版本历史”作为主入口。

## 3. 页面路由建议

```text
/teleprompter
/teleprompter?source=script&scriptId=:id
/teleprompter?source=video-package&packageId=:id
```

路由说明：

| 路由 | 说明 |
|---|---|
| /teleprompter | 空白提词器入口 |
| /teleprompter?source=script&scriptId=:id | 从 AI 脚本生成结果进入 |
| /teleprompter?source=video-package&packageId=:id | 从短视频发布包进入 |

## 4. 提词器空状态

### 页面目标

让用户快速理解如何开始提词，并提供最短输入路径。

### 页面区域

| 区域 | 内容 |
|---|---|
| 顶部栏 | 返回、页面标题、最近草稿入口 |
| 主引导区 | 粘贴脚本、导入文件、从最近脚本恢复 |
| 示例区 | 查看示例脚本 |
| 帮助区 | 快捷键说明、录制建议 |

### 核心按钮

- 粘贴脚本
- 导入 txt/md 文件
- 恢复最近草稿
- 查看示例脚本

### 空状态文案

```text
把脚本放进来，开始稳定提词
支持粘贴文案、导入文稿，或从 AI 生成脚本直接进入。
```

### 跳转

- 粘贴脚本 -> 编辑态
- 导入成功 -> 编辑态
- 恢复草稿 -> 编辑态或播放暂停态
- 返回 -> 来源页面或全案首页

## 5. 提词器编辑态

### 页面目标

让用户在开始录制前完成脚本检查、样式调整和段落确认。

### 页面布局

```text
顶部栏：返回 / 标题 / 保存状态 / 全屏预览
左侧：脚本编辑器
中间：提词预览区
右侧：设置面板 + 段落列表
底部：开始提词按钮
```

### 页面区域

| 区域 | 内容 |
|---|---|
| 顶部栏 | 返回、脚本标题、保存状态、进入全屏 |
| 脚本编辑区 | 标题输入、正文编辑、字数统计 |
| 提词预览区 | 按当前样式展示正文 |
| 设置面板 | 字号、行距、速度、主题、倒计时、镜像模式 |
| 段落列表 | 自动识别段落，支持点击定位 |
| 底部操作 | 开始提词、复制脚本、清空脚本 |

### 核心按钮

- 开始提词
- 保存草稿
- 复制脚本
- 清空脚本
- 进入全屏
- 导入文件

### 字段

| 字段 | 规则 |
|---|---|
| 脚本标题 | 默认取前20个字，可编辑 |
| 脚本正文 | 必填，最多30000字 |
| 字号 | 小、中、大、超大 |
| 行距 | 紧凑、标准、宽松 |
| 速度 | 1-10 |
| 主题 | 深色、浅色、高对比 |

### 状态

- 未保存
- 保存中
- 已保存
- 保存失败
- 字数超限
- 内容为空

## 6. 提词器播放态

### 页面目标

让用户在普通页面模式下完成稳定提词录制。

### 页面布局

```text
顶部栏：返回 / 标题 / 录制计时 / 全屏
中央：提词滚动区
右侧：段落列表，可收起
底部：播放控制栏
```

### 页面区域

| 区域 | 内容 |
|---|---|
| 提词滚动区 | 当前脚本正文，按速度向上滚动 |
| 当前段落提示 | 显示当前段落序号和段落标题 |
| 控制栏 | 播放暂停、速度、上一段、下一段、互动暂停、结束 |
| 设置入口 | 字号、行距、主题、镜像模式 |
| 段落列表 | 当前段落高亮，支持点击跳转 |

### 核心按钮

- 播放
- 暂停
- 降速
- 加速
- 上一段
- 下一段
- 互动暂停
- 进入全屏
- 结束提词

### 播放规则

| 行为 | 规则 |
|---|---|
| 点击播放 | 若开启倒计时，先显示倒计时，再开始滚动 |
| 点击暂停 | 立即停止滚动，保留当前位置 |
| 调整速度 | 当前播放立即生效 |
| 跳转段落 | 滚动位置定位到目标段落开头 |
| 结束提词 | 弹出二次确认，避免录制中误触 |

## 7. 提词器全屏态

### 页面目标

在录制时提供低干扰、清晰、稳定的提词视图。

### 页面布局

```text
全屏背景
中央提词正文
底部弱化控制浮层
右上角退出全屏
```

### 页面区域

| 区域 | 内容 |
|---|---|
| 正文区 | 大字号、高对比提词内容 |
| 进度区 | 当前段落 / 总段落，已播放进度 |
| 浮层控制 | 播放暂停、速度、上一段、下一段、互动暂停 |
| 快捷键提示 | 首次进入时短暂显示 |

### 显示规则

- 鼠标静止3秒后隐藏控制浮层。
- 鼠标移动时显示控制浮层。
- 按快捷键时显示对应操作反馈。
- Esc 退出全屏。
- 退出全屏后保留播放位置。

## 8. 直播互动暂停态

### 页面目标

让主播在直播中临时回答互动，不丢失正文进度。

### 触发入口

- 点击「互动暂停」
- 按快捷键 I

### 页面布局

```text
正文暂停背景
互动提示区
临时话术输入区
恢复正文按钮
```

### 页面区域

| 区域 | 内容 |
|---|---|
| 暂停提示 | 正文已暂停，当前位置已保留 |
| 临时话术区 | 可输入互动话术或临时提醒 |
| 快捷操作 | 恢复正文、清空临时话术、复制临时话术 |
| 原文预览 | 展示暂停位置前后若干行 |

### 核心按钮

- 恢复正文
- 清空临时话术
- 复制临时话术
- 结束提词

### 恢复规则

- 恢复正文后从原滚动位置继续。
- 临时话术不写入原脚本正文。
- 若用户选择保存临时话术，可另存为互动记录。

## 9. 文件导入弹窗

### 页面目标

支持用户从已有文稿进入提词器。

### 页面区域

| 区域 | 内容 |
|---|---|
| 上传区 | 拖拽或点击上传 |
| 格式提示 | txt、md，docx 视技术实现决定 |
| 解析结果 | 文件名、字数、段落数 |
| 错误提示 | 格式不支持、解析失败、内容为空 |

### 核心按钮

- 选择文件
- 确认导入
- 重新选择
- 取消

### 异常状态

- 文件过大
- 格式不支持
- 解析失败
- 内容为空

## 10. 快捷键说明弹窗

### 页面目标

让用户快速掌握录制中的高频操作。

### 快捷键

| 快捷键 | 操作 |
|---|---|
| Space | 播放/暂停 |
| ArrowUp | 降低速度 |
| ArrowDown | 提高速度 |
| ArrowLeft | 上一段 |
| ArrowRight | 下一段 |
| F | 进入/退出全屏 |
| Esc | 退出全屏或关闭浮层 |
| I | 互动暂停/恢复正文 |
| M | 镜像模式 |

### 规则

- 输入框聚焦时快捷键不触发播放控制。
- 首次进入播放态时显示一次快捷键提示。
- 用户可关闭提示，关闭后本地记忆。

## 11. 结束确认弹窗

### 页面目标

避免录制中误触结束。

### 弹窗内容

```text
确认结束本次提词？
当前播放位置和脚本设置将自动保存。
```

### 核心按钮

- 确认结束
- 继续提词

### 结束后展示

| 区域 | 内容 |
|---|---|
| 本次统计 | 提词时长、完成比例、字数 |
| 后续动作 | 重新播放、复制脚本、提交出片、返回脚本页 |

## 12. 响应式说明

| 设备 | 页面策略 |
|---|---|
| 桌面端 | 编辑、预览、设置三栏布局 |
| 平板横屏 | 提词区优先，设置区抽屉化 |
| 平板竖屏 | 编辑区和预览区上下排列 |
| 手机竖屏 | 单列布局，底部固定控制栏 |
| 全屏模式 | 所有设备均以正文为中心 |

## 13. 状态流

```text
空状态
  -> 编辑态
  -> 倒计时
  -> 播放态
  -> 暂停态
  -> 播放态
  -> 结束确认
  -> 结束结果
```

直播互动分支：

```text
播放态
  -> 互动暂停态
  -> 恢复正文
  -> 播放态
```

文件导入分支：

```text
空状态/编辑态
  -> 文件导入弹窗
  -> 解析中
  -> 导入成功
  -> 编辑态
```

## 14. 原型验收标准

| 验收项 | 通过标准 | 是否通过 |
|---|---|---|
| 空状态 | 用户能看到粘贴、导入、恢复草稿入口 |  |
| 编辑态 | 脚本编辑、预览、设置、段落列表完整 |  |
| 播放态 | 播放、暂停、调速、跳段、结束可操作 |  |
| 全屏态 | 控制浮层可隐藏和唤起 |  |
| 互动暂停 | 能暂停正文并恢复原位置 |  |
| 文件导入 | 有导入成功和失败状态 |  |
| 快捷键提示 | 能看到完整快捷键说明 |  |
| 响应式 | 桌面、平板、手机有明确布局策略 |  |

## 15. 小P结论

V0.1 原型不需要展示复杂 AI 能力，重点是把录制现场的高频控制打磨清楚。

设计验收时只看一件事：

```text
用户拿到一篇脚本后，能不能在 1 分钟内开始稳定提词。
```
