# IP资产建档模板

本模板用于为产品、人物IP、宠物IP、空间门店建立长期可复用的视觉与内容资产档案。每个资产档案是后续短视频生成、栏目规划、选题生产和发布复盘的基础。

## 建档原则

- 先固定主体一致性，再生成内容。
- 先记录禁改项，再扩展场景。
- 资产档案要能被反复调用，而不是只服务单条视频。
- 每个产品、人物、宠物、空间都应单独建档。
