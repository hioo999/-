# 发布数据复盘模板

本模板用于记录短视频发布后的数据表现，并反推下一轮选题、分镜、脚本和发布策略。

```text
所属栏目：
平台：

发布时间段：

曝光量：
播放量：
完播率：
平均观看时长：
点赞数：
评论数：
收藏数：
转发数：
关注转化：
私信/表单/成交数据：
```

## 内容表现分析

```text
前3秒钩子表现：好 / 中 / 差
用户主要评论：
用户最关心的问题：
表现最好的镜头：

卖点/观点是否被理解：
是否符合IP人设：
```


## 复盘提示词

```text
请根据以下短视频发布数据做内容复盘，并给出下一轮优化建议。

视频信息：{{视频信息}}
发布数据：{{发布数据}}
评论反馈：{{评论反馈}}
IP定位：{{IP定位}}
商业目标：{{商业目标}}

请输出：
1. 数据表现判断。
2. 前3秒钩子是否有效。
3. 标题和封面是否有效。
4. 分镜和脚本哪里有效、哪里无效。
5. 用户真正关心的问题。
6. 下一轮可复用元素。
7. 下一轮必须避免的问题。
8. 10条新选题建议。
9. 3条可直接执行的优化动作。
```
