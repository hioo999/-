# 单条视频项目归档模板

本模板用于把一条短视频从需求、资产、分镜、脚本、生成提示词到发布文案完整归档，方便复用和复盘。

## 项目信息

```text
项目名称：
创建日期：
负责人：
所属IP/品牌：
视频类型：产品TVC / 宠物Vlog / 人物IP / 知识口播 / 生活方式 / 空间探店
目标平台：抖音 / 小红书 / 视频号 / B站 / 快手
画面比例：16:9 / 9:16 / 1:1
视频时长：
商业目标：涨粉 / 种草 / 私域 / 成交 / 品牌认知
```

```text
情绪基调：
参考风格：
禁用方向：
```
