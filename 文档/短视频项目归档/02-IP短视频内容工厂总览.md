# IP短视频内容工厂总览

本文件用于说明 IP 全案中短视频内容工厂的完整闭环。

## 系统定位

IP短视频内容工厂不是单条视频生成工具，而是一套围绕 IP 长期生产、发布、复盘和优化的内容系统。

## 完整链路

```text
IP定位
↓
IP资产建档
↓
内容栏目规划
↓
短视频选题生成
↓
前3秒钩子设计
↓
主体清理与四视图/角色设定图
↓
九宫格分镜
↓
15秒动态脚本
↓
最终视频模型提示词
↓
AI视频生成
↓
质检与重生成
↓
标题封面发布文案
↓
发布数据复盘
↓
下一轮栏目与选题优化
```

## 模块关系

- IP资产库：解决主体一致性和长期复用。
- IP内容栏目库：解决长期做什么内容。
- 短视频选题生成器：解决每周具体拍什么。
- 前3秒钩子库：解决打开率。
- AI短视频生产系统：解决分镜、脚本和视频提示词。
- 项目归档：解决单条视频沉淀。
- 发布复盘：解决下一轮优化。

## 使用顺序

新IP建议使用：

```text
/IP资产建档 → /栏目规划 → /短视频选题 → /前3秒钩子 → /短视频工作流 → /视频项目归档 → /发布复盘
```

已有IP建议使用：

```text
/短视频选题 → /短视频工作流 → /短视频质检 → /视频项目归档 → /发布复盘
```

产品广告建议使用：

```text
/IP资产建档 → /产品TVC → /短视频质检 → /视频项目归档
```

宠物IP建议使用：

```text
/IP资产建档 → /宠物Vlog → /短视频质检 → /发布复盘
```
