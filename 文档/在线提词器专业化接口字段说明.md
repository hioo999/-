# 在线提词器专业化接口字段说明

## 1. 文档目标

本文档定义在线提词器专业化 V0.1 的接口边界、请求字段、响应结构、枚举和错误码口径，供前后端联调使用。

V0.1 接口原则：

- 基础提词闭环优先，云端草稿可作为增强能力。
- 前端本地草稿必须可独立工作。
- 来源脚本读取需要保持字段稳定。
- 提词设置、滚动位置、段落位置要可保存和恢复。
- 埋点事件结构统一，便于后续分析录制完成率。

## 2. 通用响应结构

成功响应：

```json
{
  "success": true,
  "data": {},
  "message": "ok"
}
```

失败响应：

```json
{
  "success": false,
  "code": "TELEPROMPTER_DRAFT_NOT_FOUND",
  "message": "提词器草稿不存在或已删除。",
  "detail": "draft id not found"
}
```

分页响应：

```json
{
  "success": true,
  "data": {
    "items": [],
    "page": 1,
    "pageSize": 20,
    "total": 100
  },
  "message": "ok"
}
```

## 4. 数据结构

### 4.1 TeleprompterSettings

```json
{
  "fontSize": "large",
  "lineHeight": "normal",
  "scrollSpeed": 5,
  "theme": "dark",
  "mirrorMode": false,
  "countdownEnabled": true,
  "countdownSeconds": 3
}
```

字段说明：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| fontSize | string | 是 | small、medium、large、xlarge |
| lineHeight | string | 是 | compact、normal、loose |
| scrollSpeed | number | 是 | 1-10 |
| theme | string | 是 | dark、light、contrast |
| mirrorMode | boolean | 是 | 是否镜像显示 |
| countdownEnabled | boolean | 是 | 是否开启倒计时 |
| countdownSeconds | number | 否 | 3、5、10 |

### 4.2 TeleprompterParagraph

```json
{
  "id": "paragraph_001",
  "index": 0,
  "text": "很多人职业选错，不是因为不努力。",
  "previewText": "很多人职业选错，不是因为不努力。",
  "wordCount": 16,
  "startOffset": 0,
  "endOffset": 16
}
```

字段说明：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| id | string | 是 | 段落ID |
| index | number | 是 | 段落序号，从0开始 |
| text | string | 是 | 段落全文 |
| previewText | string | 是 | 段落预览，建议30字以内 |
| wordCount | number | 是 | 段落字数 |
| startOffset | number | 否 | 在全文中的起始位置 |
| endOffset | number | 否 | 在全文中的结束位置 |

### 4.3 TeleprompterDraft

```json
{
  "draftId": "tp_draft_001",
  "userId": "user_001",
  "title": "听建议没用，职业方向要这样算",
  "content": "很多人职业选错，不是因为不努力。\n而是一开始算法就错了。",
  "settings": {
    "fontSize": "large",
    "lineHeight": "normal",
    "scrollSpeed": 5,
    "theme": "dark",
    "mirrorMode": false,
    "countdownEnabled": true,
    "countdownSeconds": 3
  },
  "currentParagraphIndex": 0,
  "currentScrollPosition": 120,
  "source": "video_package",
  "sourceId": "video_package_001",
  "wordCount": 36,
  "paragraphCount": 2,
  "status": "editing",
  "createdAt": "2026-05-24T16:00:00+08:00",
  "updatedAt": "2026-05-24T16:10:00+08:00"
}
```

字段说明：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| draftId | string | 是 | 草稿ID |
| userId | string | 否 | 用户ID |
| title | string | 是 | 草稿标题 |
| content | string | 是 | 脚本正文，最多30000字 |
| settings | object | 是 | 提词器设置 |
| currentParagraphIndex | number | 是 | 当前段落索引 |
| currentScrollPosition | number | 是 | 当前滚动位置 |
| source | string | 是 | 来源类型 |
| sourceId | string | 否 | 来源ID |
| wordCount | number | 是 | 字数 |
| paragraphCount | number | 是 | 段落数 |
| status | string | 是 | 草稿状态 |
| createdAt | string | 是 | 创建时间 |
| updatedAt | string | 是 | 更新时间 |

## 5. 获取AI脚本详情

接口：`GET /api/scripts/:id`

用途：从 AI 脚本生成结果页进入提词器时，读取脚本标题和正文。

响应：

```json
{
  "success": true,
  "data": {
    "scriptId": "video_script_001",
    "title": "听建议没用，职业方向要这样算",
    "content": "很多人职业选错，不是因为不努力。\n而是一开始算法就错了。",
    "platform": "shipinhao",
    "source": "script",
    "estimatedDuration": 45,
    "updatedAt": "2026-05-24T16:00:00+08:00"
  },
  "message": "ok"
}
```

响应字段：

| 字段 | 说明 |
|---|---|
| scriptId | 脚本ID |
| title | 脚本标题 |
| content | 可用于提词的正文 |
| platform | 平台 |
| source | 固定为 script |
| estimatedDuration | 预估口播时长，单位秒 |
| updatedAt | 更新时间 |

## 6. 获取短视频发布包提词脚本

接口：`GET /api/video-packages/:id/teleprompter-script`

用途：从短视频发布包进入提词器时，读取口播稿。

```json
    "durationEstimate": 45,
    "source": "video_package",
    "updatedAt": "2026-05-24T16:00:00+08:00"
  },
  "message": "ok"
}
```

响应字段：

| 字段 | 说明 |
|---|---|
| packageId | 短视频发布包ID |

| title | 脚本标题 |
| content | 口播脚本正文 |

## 7. 创建提词器草稿

接口：`POST /api/teleprompter/drafts`

用途：保存云端草稿。V0.1 如暂不做云端草稿，前端可使用 Mock 结构保持兼容。

请求：

```json
{
  "title": "听建议没用，职业方向要这样算",
  "content": "很多人职业选错，不是因为不努力。\n而是一开始算法就错了。",
  "settings": {
    "fontSize": "large",
    "lineHeight": "normal",
    "scrollSpeed": 5,
    "theme": "dark",
    "mirrorMode": false,
    "countdownEnabled": true,
    "countdownSeconds": 3
  },
  "currentParagraphIndex": 0,
  "currentScrollPosition": 120,
  "source": "video_package",
  "sourceId": "video_package_001"
}
```

响应：

```json
{
  "success": true,
  "data": {
    "draftId": "tp_draft_001",
    "status": "saved",
    "updatedAt": "2026-05-24T16:10:00+08:00"
  },
  "message": "提词器草稿保存成功"
}
```

校验规则：

| 字段 | 规则 |
|---|---|
| title | 最多50字，缺省时取正文前20字 |
| content | 必填，最多30000字 |
| scrollSpeed | 1-10 |
| currentParagraphIndex | 不小于0 |
| currentScrollPosition | 不小于0 |

## 12. 上报提词器埋点

接口：`POST /api/analytics/events`

请求：

```json
{
  "eventName": "teleprompter_start",
  "eventTime": "2026-05-24T16:20:00+08:00",
  "userId": "user_001",
  "sessionId": "session_001",
  "properties": {
    "source": "video_package",
    "sourceId": "video_package_001",
    "wordCount": 36,
    "paragraphCount": 2,
    "scrollSpeed": 5,
    "fontSize": "large",
    "theme": "dark",
    "device": "desktop",
    "browser": "Chrome"
  }
}
```

响应：

```json
{
  "success": true,
  "data": {
    "accepted": true
  },
  "message": "ok"
}
```

事件列表：

| 事件名 | 触发时机 |
|---|---|
| teleprompter_open | 用户进入提词器 |
| teleprompter_script_import | 粘贴或导入脚本成功 |
| teleprompter_start | 用户开始提词 |
| teleprompter_pause | 用户暂停提词 |
| teleprompter_resume | 用户恢复提词 |
| teleprompter_speed_change | 用户调整速度 |
| teleprompter_fullscreen_enter | 用户进入全屏 |
| teleprompter_paragraph_jump | 用户跳转段落 |
| teleprompter_interaction_pause | 用户触发互动暂停 |
| teleprompter_finish | 用户结束提词 |
| teleprompter_error | 出现异常 |

## 14. 错误码

| 错误码 | 说明 | 前端处理 |
|---|---|---|
| TELEPROMPTER_SCRIPT_NOT_FOUND | 来源脚本不存在 | 提示脚本不存在，允许返回来源页 |
| TELEPROMPTER_PACKAGE_NOT_FOUND | 短视频发布包不存在 | 提示发布包不存在，允许返回短视频工作台 |
| TELEPROMPTER_DRAFT_NOT_FOUND | 草稿不存在 | 提示草稿不存在，允许新建 |
| TELEPROMPTER_CONTENT_EMPTY | 内容为空 | 禁止保存或开始提词 |
| TELEPROMPTER_CONTENT_TOO_LONG | 内容超过30000字 | 提示拆分脚本 |
| TELEPROMPTER_SETTINGS_INVALID | 设置参数非法 | 使用默认设置并提示 |
| TELEPROMPTER_SAVE_FAILED | 草稿保存失败 | 提示保存失败，不阻塞当前提词 |
| TELEPROMPTER_ANALYTICS_FAILED | 埋点上报失败 | 静默失败或进入重试队列 |

## 15. 联调验收

| 验收项 | 通过标准 | 是否通过 |
|---|---|---|
| 来源脚本读取 | scriptId 有效时返回标题和正文 |  |
| 发布包脚本读取 | packageId 有效时返回口播脚本 |  |
| 草稿创建 | 请求合法时返回 draftId |  |
| 草稿更新 | 更新后 updatedAt 变化 |  |
| 最近草稿 | 有草稿返回摘要，无草稿返回 null |  |
| 指定草稿 | draftId 有效时返回完整内容和设置 |  |
| 错误结构 | 失败时返回 code、message、detail |  |
| 埋点上报 | 事件可被服务端接收 |  |
