# 短视频选题生成器模板

本模板用于根据 IP 定位、目标用户、内容栏目和平台特点，批量生成短视频选题。

## 选题生成提示词

```text
请基于以下 IP 信息，生成30条短视频选题。

IP名称：{{IP名称}}
IP类型：{{IP类型}}
IP定位：{{IP定位}}
目标受众：{{目标受众}}
核心优势/卖点：{{核心优势}}
商业目标：{{商业目标}}
目标平台：{{平台}}
可用栏目：{{栏目列表}}
禁用方向：{{禁用方向}}

要求：
1. 每条选题都要有明确目标，不要泛泛而谈。
2. 前10条偏涨粉，11-20条偏信任建立，21-30条偏转化。
3. 每条选题都要标注适合的栏目和视频类型。
4. 选题要能继续进入九宫格分镜和视频脚本生产。

输出格式：
序号：
选题标题：
适合栏目：
视频类型：TVC / Vlog / 口播 / 剧情 / 种草 / 探店
目标平台：
目标用户：
3秒钩子：
核心内容：
可用素材：
转化目标：
下一步建议：九宫格分镜 / 口播脚本 / 产品TVC / 宠物Vlog / 人物IP短片
```

## 选题质检标准

- 是否有明确受众。
- 是否能在3秒内吸引人。
- 是否服务一个栏目。
- 是否能进入视频生产链路。
- 是否符合IP人设或品牌调性。
- 是否有商业目标。
- 是否避免标题党和虚假承诺。
