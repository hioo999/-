# IP内容栏目规划模板

本模板用于把 IP 定位转化为可长期更新的内容栏目矩阵。栏目库解决的是“长期做什么内容”，短视频生产系统解决的是“每条内容怎么生成”。

## 栏目规划输入

```text
IP名称：
IP类型：产品 / 人物 / 宠物 / 空间 / 企业品牌
IP定位：
目标受众：
核心优势：
商业目标：涨粉 / 种草 / 私域 / 成交 / 招募 / 品牌认知
主要平台：
更新频率：
可用素材：
禁用方向：
```

## 栏目规划输出

```text
栏目名称：
栏目定位：
目标用户：
解决的问题：
内容形式：TVC / Vlog / 口播 / 剧情 / 测评 / 探店 / 直播切片
推荐时长：
推荐比例：
发布频率：
选题方向：
可复用资产：
转化路径：
代表选题：
```

## 产品IP栏目库

- 产品TVC大片：建立品牌质感和产品高级感。
- 使用场景种草：展示产品在真实生活中的使用价值。
- 成分/工艺讲解：解释产品为什么值得信任。
- 用户痛点解决：从用户问题切入产品卖点。
- 品牌故事：讲品牌理念、产地、创始故事。
- 节日营销：结合节气、节日、礼赠场景。
- 对比测评：和常见替代品做差异化表达。
- 开箱体验：用真实拆箱和第一感受降低决策门槛。

## 人物IP栏目库

- 观点输出：建立判断力和专业权威。
- 案例拆解：用真实案例证明能力。
- 行业判断：表达趋势、机会和风险。
- 认知反差：用反常识提高打开率。
- 个人故事：增强信任和人格魅力。
- 热点点评：借势热点表达专业观点。
- 学员/客户故事：呈现结果和转化证明。
- 直播切片：复用高密度表达内容。

## 宠物IP栏目库

- 日常Vlog：记录真实生活，建立陪伴感。
- 宠物小剧场：用轻剧情制造传播点。
- 治愈瞬间：突出可爱、温暖、陪伴。
- 宠物拟人剧情：强化IP性格。
- 主人互动：建立关系感和情绪价值。
- 产品植入：自然融入宠物用品或生活好物。
- 成长记录：持续记录变化，增强追更动机。
- 节日主题：结合春节、圣诞、生日等节点。

## 空间门店栏目库

- 门店探店：展示环境、体验和服务。
- 空间美学：突出设计、灯光、材质和氛围。
- 产品/菜品/服务展示：呈现核心消费理由。
- 一日运营：展示真实经营细节。
- 用户体验：从顾客视角讲感受。
- 老板/主理人故事：建立品牌温度。
- 活动现场：呈现人气和社交氛围。
- 城市生活方式：把空间放入城市文化语境。
