# IP全案系统P0低保真原型任务分解

## 1. 文档目标

本文档用于指导设计侧完成P0低保真原型。P0原型不是视觉稿，不追求完整视觉风格，目标是确认信息架构、页面流程、关键状态和操作路径。

## 2. 原型优先级

### 第一优先级

- 全案首页
- IP资产详情页
- 内容母稿页
- 公众号工作台
- 公众号排版预览页
- 公众号草稿同步页
- 小红书发布包页

### 第二优先级

- 小红书工作台
- 短视频工作台
- 短视频发布包页
- 朋友圈工作台
- 图片生成中心
- 发布授权页

### 第三优先级

- IP资产列表页
- 栏目矩阵页
- 选题库页
- 素材库页
- 模板库页

## 3. 原型交付标准

每个页面必须包含：

- 页面目标
- 页面区域划分
- 关键字段
- 主按钮
- 次按钮
- 空状态
- 生成中状态
- 生成失败状态
- 保存成功状态
- 页面跳转关系

## 4. 全案首页原型任务

### 页面目标

用户进入系统后能快速选择IP，并进入四条产品线。

### 必须画出的区域

- 当前IP选择器
- 创建IP按钮
- 公众号入口卡片
- 小红书入口卡片
- 短视频入口卡片
- 朋友圈入口卡片
- 待办列表
- 授权状态提醒
- 最近生成内容

### 状态

- 无IP空状态
- 有IP正常状态
- 公众号未授权提醒
- 图片模型未配置提醒

### 关键跳转

- 创建IP → IP资产详情页
- 公众号入口 → 公众号工作台
- 小红书入口 → 小红书工作台
- 短视频入口 → 短视频工作台
- 朋友圈入口 → 朋友圈工作台


## 16. 原型评审顺序

建议按以下顺序评审：

```text
全案首页
↓
IP资产详情 + 内容母稿
↓
公众号工作台 + 排版预览 + 草稿同步
↓
小红书工作台 + 发布包
↓
短视频工作台
↓
朋友圈工作台
↓
图片生成中心 + 发布授权
```

## 17. 原型验收标准

- 主流程从创建IP到四平台输出可完整点击。
- 公众号草稿同步链路有独立页面和错误状态。
- 小红书发布包能清楚展示图片和文案对应关系。
- 短视频页面明确区分抖音和视频号。
- 朋友圈页面突出私域承接，不像公域内容生成器。
- 图片生成中心可被各平台复用。
- 发布授权页有明确安全提示。
- 提词器核心功能不在原型改造范围内。
