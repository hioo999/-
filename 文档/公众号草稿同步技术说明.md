# 公众号草稿同步技术说明

## 1. 文档目标

本文档用于指导P0阶段实现公众号草稿箱同步能力。

P0只实现：

```text
生成公众号文章 -> 自动排版 -> 上传封面 -> 创建公众号草稿
```

P0不实现：

- 不直接群发。
- 不自动发布。
- 不绕过公众号后台审核。
- 不承诺所有公众号账号都具备接口权限。

## 2. 总流程

```text
用户配置公众号AppID/AppSecret
↓
系统加密保存AppSecret
↓
测试授权并获取access_token
↓
生成公众号文章
↓
生成摘要和封面
↓
生成公众号兼容HTML
↓
上传封面素材获取thumb_media_id
↓
处理正文图片
↓
调用草稿接口draft/add
↓
返回草稿同步结果
```

## 3. 授权配置

### 3.1 配置字段

```text
公众号名称
AppID
AppSecret
默认作者
默认原文链接
是否开启评论
是否仅粉丝评论
```

### 3.2 安全要求

- AppSecret必须后端加密存储。
- 前端保存后不得再次展示完整AppSecret。
- 前端只展示脱敏信息，例如：`已配置，尾号 9f3a`。
- 更新AppSecret需要重新输入完整值。
- 删除授权需要二次确认。
- 授权操作写入操作日志。

### 3.3 授权状态

```text
not_configured
configured_not_tested
valid
invalid
expired
```

## 4. access_token处理

### 4.1 获取token

请求微信接口获取access_token。

后端内部流程：

```text
读取加密AppSecret
↓
解密AppSecret
↓
请求微信token接口
↓
保存access_token和过期时间
↓
返回授权测试结果
```

### 4.2 缓存策略

- access_token应缓存。
- 过期前提前刷新。
- 刷新失败时保留旧token到实际过期，但标记为需要重试。
- 不要每次草稿同步都重新获取token，避免限频。

### 4.3 常见失败

| 场景 | 系统提示 |
|---|---|
| AppID错误 | AppID无效，请检查公众号开发配置。 |
| AppSecret错误 | AppSecret无效，请重新填写。 |
| IP白名单错误 | 当前服务器IP未加入公众号后台白名单。 |
| 接口限频 | 微信接口调用过于频繁，请稍后重试。 |
| 网络超时 | 微信接口响应超时，请稍后重试。 |

## 5. 封面上传

### 5.1 封面来源

P0支持两类封面来源：

- AI生成封面。
- 用户上传封面。

### 5.2 上传前检查

上传前必须检查：

- 图片存在。
- 图片格式符合微信要求。
- 图片大小符合微信要求。
- 图片可被后端读取。
- 图片不是临时失效地址。

### 5.3 上传结果

上传成功后保存：

```text
thumb_media_id
materialId
wechatAuthId
uploadedAt
```

### 5.4 失败处理

| 场景 | 用户提示 |
|---|---|
| 图片过大 | 封面图片过大，请压缩后重试。 |
| 格式不支持 | 封面格式不支持，请使用JPG或PNG。 |
| access_token失效 | 授权已过期，系统将重新获取token后重试。 |
| 上传接口失败 | 封面上传失败，请稍后重试。 |

## 6. 正文图片处理

P0建议先采用可控方案：

```text
正文图片先上传到公众号素材或可访问CDN，再写入HTML。
```

### 6.1 处理方式

方案A：上传到公众号图片接口，使用微信返回URL。

方案B：上传到对象存储/CDN，确保微信后台可访问。

P0优先建议方案A，避免外部图片在公众号后台显示异常。

### 6.2 插图位置

正文图片由文章结构决定：

```text
开头后：主题图
方法论段落：结构图
案例段落：案例图
金句段落：金句图
文末：转化图或二维码
```

P0正文配图可先手动插入或自动建议插入，不要求复杂可视化拖拽。

## 7. HTML生成

### 7.1 生成原则

- 使用内联CSS。
- 不使用script。
- 不依赖外部CSS文件。
- 避免复杂布局。
- 避免微信编辑器不支持的标签。
- 段落样式优先保证可读性。

### 7.2 P0默认模板

P0至少提供一个默认模板：

```text
极简知识型模板
```

包含：

- 标题。
- 作者。
- 开头引导。
- 一级标题。
- 正文段落。
- 引用块。
- 重点加粗。
- 分割线。
- 图片。
- 文末转化区。

### 7.3 HTML检查

草稿同步前检查：

- contentHtml非空。
- 标题非空。
- 摘要非空。
- 封面thumb_media_id存在。
- 正文图片URL有效。
- HTML长度不超过接口限制。

## 8. 创建草稿

### 8.1 草稿参数

创建草稿需要组装：

```text
title
author
digest
content
content_source_url
thumb_media_id
need_open_comment
only_fans_can_comment
```

### 8.2 P0单图文

P0优先支持单篇图文草稿。

不做多篇图文合并，不做批量草稿。

### 8.3 成功结果

成功后记录：

```text
platformContentId
wechatAuthId
wechatDraftMediaId
syncedAt
syncStatus
```

前端展示：

```text
草稿同步成功，请前往公众号后台草稿箱确认内容。
```

## 9. 同步状态流

```text
not_started
↓
checking_auth
↓
getting_token
↓
uploading_cover
↓
processing_images
↓
rendering_html
↓
creating_draft
↓
synced
```

失败状态：

```text
auth_failed
token_failed
cover_upload_failed
image_process_failed
html_invalid
draft_create_failed
timeout
```

## 10. 错误码映射

| 系统错误码 | 场景 | 用户提示 |
|---|---|---|
| WECHAT_AUTH_MISSING | 未配置授权 | 请先配置公众号AppID和AppSecret。 |
| WECHAT_AUTH_FAILED | 授权失败 | 公众号授权失败，请检查AppID和AppSecret。 |
| WECHAT_IP_NOT_ALLOWED | IP白名单错误 | 当前服务器IP未加入公众号后台白名单，请到公众号后台配置。 |
| WECHAT_TOKEN_FAILED | token获取失败 | 获取公众号access_token失败，请稍后重试。 |
| WECHAT_COVER_MISSING | 封面缺失 | 请先生成或上传公众号封面。 |
| WECHAT_COVER_UPLOAD_FAILED | 封面上传失败 | 封面上传失败，请检查格式和大小。 |
| WECHAT_HTML_INVALID | HTML不兼容 | 文章排版存在不兼容内容，请重新排版。 |
| WECHAT_DRAFT_CREATE_FAILED | 草稿创建失败 | 草稿同步失败，请查看详情后重试。 |
| WECHAT_RATE_LIMIT | 接口限频 | 公众号接口调用频繁，请稍后重试。 |

## 11. 前端页面提示

### 11.1 授权配置提示

```text
AppID和AppSecret仅用于同步公众号草稿，系统将加密保存，不会明文展示。
```

### 11.2 IP白名单提示

```text
如果测试授权失败并提示IP白名单，请进入公众号后台「开发设置」，添加服务器IP后重试。
```

### 11.3 草稿同步成功提示

```text
已成功同步到公众号草稿箱。请前往公众号后台检查排版、图片和链接后再发布。
```

### 11.4 草稿同步失败提示

错误提示格式：

```text
同步失败：{失败原因}
处理建议：{用户可执行动作}
```

## 12. 日志要求

后端需要记录：

- 授权保存时间。
- 授权测试结果。
- access_token刷新结果。
- 封面上传结果。
- 草稿同步请求ID。
- 草稿同步结果。
- 微信接口错误码。

日志不得记录完整AppSecret和完整access_token。

## 13. 安全要求

- AppSecret加密存储。
- access_token加密或安全存储。
- 前端不返回完整密钥。
- 日志脱敏。
- 删除授权时清除密钥和token缓存。
- 草稿同步接口需要校验当前用户对公众号授权的使用权限。

## 14. P0验收标准

- 可以保存公众号AppID和AppSecret。
- 可以测试授权状态。
- 可以获取并缓存access_token。
- 可以上传封面并获得thumb_media_id。
- 可以将公众号兼容HTML同步到草稿箱。
- 同步成功后有明确提示。
- 同步失败后有明确原因和处理建议。
- 不支持直接群发。
- 不暴露AppSecret和access_token。
