# 图片模型Demo验收标准

## 1. 文档目标

本文档用于Sprint 0验证图片模型是否能支撑P0需求，包括公众号封面、小红书封面、小红书正文配图。

P0图片模型Demo不要求最终视觉完美，但必须证明链路可行、质量可控、失败可处理。

## 2. Demo范围

必须验证：

- 公众号封面生成。
- 小红书封面生成。
- 小红书正文配图生成。
- 参考图使用。
- 指定比例。
- 图片保存。
- 失败重试。

暂不验证：

- 小红书自动发布。
- 复杂图片编辑器。
- 批量商业海报模板。
- 视频生成。

## 3. 测试输入

统一测试主题：

```text
职业方向别乱选，先看这3个判断标准
```

IP信息：

```text
IP类型：专家IP
行业：职业规划
目标用户：大学生和职场新人
视觉风格：真实、清爽、知识感、可信
```

## 4. 必测图片

### IMG-DEMO-01 公众号封面

要求：

- 主题明确。
- 适合公众号列表页。
- 可用于文章头图。
- 画面干净，不杂乱。
- 可留标题字区域。

建议提示词：

```text
公众号文章封面，主题是职业规划和方向选择，清爽专业的知识感视觉，书桌、笔记本、便签、柔和光线，适合公众号列表页点击，画面干净可信，预留标题区域，不要夸张，不要低质感，不要乱码文字。
```

验收：

- 至少生成1张可用图。
- 图片可保存素材库。
- 图片URL可被后端访问。

### IMG-DEMO-02 小红书封面

要求：

- 适合小红书3:4图文封面。
- 有点击感。
- 画面真实，有干货感。
- 标题区域明显。

建议提示词：

```text
小红书干货封面图，主题是职业方向选择，真实明亮的书桌场景，笔记本电脑、便签纸、简洁背景，画面上方留出标题区域，整体风格清爽、真实、有收藏感，不要夸张商业海报，不要复杂背景，不要乱码文字。
```

验收：

- 至少生成1张3:4封面图。
- 标题区域清楚。
- 图片不明显变形。

### IMG-DEMO-03 小红书正文配图

要求：

- 至少生成3张。
- 每张图用途不同。
- 支持知识卡片或生活方式图。

三张图用途：

```text
图1：痛点图，为什么越听建议越迷茫
图2：方法图，选方向先看3件事
图3：行动引导图，评论区留下专业+城市+目标方向
```

验收：

- 三张图均生成成功。
- 每张图能保存素材库。
- 每张图保留生成提示词。

## 5. 模型能力检查

| 能力 | 是否必须 | 验收标准 |
|---|---|---|
| 文生图 | 是 | 能根据提示词生成图 |
| 图生图 | P0建议 | 能使用参考图生成变体 |
| 指定比例 | 是 | 支持公众号封面和小红书3:4 |
| 图中文字 | P0建议 | 可生成或预留文字区域 |
| 失败重试 | 是 | 失败后可重新生成 |
| 结果保存 | 是 | 可保存到素材库 |
| 任务状态 | 是 | 有生成中、成功、失败状态 |

## 6. 质量验收标准

### 6.1 基础质量

- 图片清晰。
- 主题相关。
- 无明显畸变。
- 无明显低质感。
- 不出现恐怖或违规画面。

### 6.2 平台适配

公众号封面：

- 稳重、清晰、适合文章点击。
- 不要过于小红书化。

小红书封面：

- 有点击感。
- 生活化或干货感。
- 适合3:4浏览。

小红书配图：

- 有收藏价值。
- 信息结构清楚。
- 不像硬广。

### 6.3 风险检查

- 图片文字不得明显乱码。
- 人物不得换脸误导。
- 产品不得变形。
- 不得生成侵权品牌标识。
- 不得出现违法违规元素。

## 8. 失败场景验收

必须验证：

- API Key错误。
- 模型接口超时。
- 提示词违规。
- 参考图不存在。
- 图片保存失败。

每个失败场景必须返回：

```text
错误码
用户提示
是否可重试
处理建议
```

## 9. Demo通过标准

图片模型Demo通过必须满足：

- 公众号封面生成成功。
- 小红书封面生成成功。
- 小红书正文配图至少3张生成成功。
- 图片可保存到素材库。
- 图片生成失败可识别并重试。
- 生成结果记录模型、提示词、耗时、URL。

## 10. 不通过处理

如果图片模型Demo不通过，必须明确降级方案：

```text
方案A：换模型
方案B：只生成提示词，人工到外部工具生成
方案C：使用模板叠字和素材库图片
方案D：P0只做小红书文案包，图片生成后置P1
```

产品建议：如果公众号草稿同步已跑通，但图片模型质量不稳定，P0不能阻塞公众号主链路，可以先允许用户上传封面作为兜底。
