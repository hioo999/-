## 4. 本次发现的问题与处理

### 4.1 Agent Console 脚手架缺失

初次执行 `verify-mvp.sh` 时，`npm run check:scaffold` 失败。

失败原因：

```text
missing required scaffold file: src/pages/AgentStatusPage.tsx
```

处理动作：

| 动作 | 说明 |
|---|---|
| 恢复交付验收入口 | 增加 `DeliveryAcceptancePage` 与 `delivery` 路由 |
| 补齐基础页面文件 | 增加 `AgentStatusPage`、`TasksPage`、`CasesPage`、`RagChatPage` |
| 保留现有主流程 | 不改变知识库工作台作为当前主入口的产品定位 |

### 4.2 交付验收 UI 合同缺失

失败原因：`DeliveryAcceptancePage` 缺失，无法满足 P0-09 交付验收包 UI 合同。

处理动作：恢复交付验收页，明确以下验收文案：

| 文案/要素 | 目的 |
|---|---|
| `metadata-only` | 强调验收报告只含元数据 |
| `平台不可见` | 强调平台侧不接收业务数据 |
| `不展示案件` | 避免 UI 示例泄露业务内容 |
| `bash scripts/verify-mvp.sh` | 给出客户解包复验入口 |
| `harness-engineering-delivery.tar.gz.sha256` | 保留完整性校验物 |
| `delivery-acceptance-report.json` | 保留验收报告 |
| `delivery-bundle-manifest.json` | 保留 bundle manifest |

### 4.3 构建产物过期

`check-delivery-ui` 会在存在 `dist/` 时检查构建产物。首次源码修复后，旧 `dist/` 仍缺少交付验收文案。

处理动作：重新执行 Agent Console 生产构建，使源码与构建产物一致。
