## 重点测试场景

### 1. IP 全案生成链路

- 链接/文本/文件输入后能正确提取核心内容。
- 一键生成后能得到口播文案、分镜提示词、封面提示词。
- AI Copilot 可对当前内容进行流式修改。
- 复制、切换标签、空状态、错误状态表现正确。

### 2. 反转剧编剧

- 必填项校验正确。
- 自定义人物增删正常。
- 生成结果包含概览、分镜、结尾字幕、自检清单。
- Markdown 复制可用。

### 3. 在线提词器

| 测试点 | 验证内容 |
|--------|----------|
| 文件导入 | txt/md/doc/docx 导入成功，损坏文件提示明确 |
| 播放控制 | 播放、暂停、重置、快退、快进、跳开头、跳末尾 |
| 快捷键 | Space、Enter、方向键、PageUp/PageDown、Home/End、+/- |
| 全屏/镜像 | 全屏进入退出，镜像模式正常 |
| 语音跟读 | 读到文案自动定位，不匹配暂停等待，当前句高亮 |
| 互动暂停 | 临场发挥时暂停，讲回文案后能继续跟随 |
| 段落跳转 | 自动识别段落，点击可跳转 |

### 4. AI 出片

- 无文案时不能提交。
- 视频引擎未就绪时提示清晰。
- 任务提交后显示 pending/running/succeeded/failed 状态。
- 进度条、视频预览、下载链接正确。

### 5. 公众号排版与草稿发布

| 测试点 | 验证内容 |
|--------|----------|
| 入口与带入 | 从首页和工作台进入公众号排版，二创内容自动带入 Markdown 编辑器 |
| 账号配置 | 新增、编辑、删除公众号账号；首次保存必须填写 AppSecret；编辑留空不覆盖密钥 |
| 连接测试 | AppID/AppSecret 正确时测试成功；错误、IP 白名单缺失、账号无权限时提示明确 |
| 主题渲染 | feishu2weixin 账号和主题 ID 正确时生成主题 HTML；失败时展示错误并可使用内置排版 |
| HTML 安全 | Markdown 和远程 HTML 注入 script、onerror、javascript 链接后，预览不执行脚本 |
| 图片安全 | 封面和正文图片拒绝 localhost、私网、云元数据地址、非图片类型、超大图片和重定向绕过 |
| 草稿发送 | 成功后返回微信 media_id，状态为 sent，公众号后台草稿箱可见 |
| 失败记录 | token、封面上传、正文图上传、draft/add 失败时状态为 failed，并展示可理解错误 |
| 越权隔离 | 用户 A 的公众号账号和草稿记录，用户 B 不能读取、测试、发送或删除 |
| 复制导出 | Markdown 和 HTML 复制成功；浏览器禁止剪贴板时提示手动复制 |

## 测试方法论

### 1. 先测核心闭环

优先验证 `素材输入 → AI 生成 → 内容编辑 → 提词播放 → 出片任务` 能否完整跑通，再扩展到高级设置和边缘功能。

### 2. 按风险决定深度

涉及直播控制、语音识别、文件导入、AI 生成、视频任务、安全合规的功能默认提高测试等级。

### 3. 用状态机覆盖异常

对生成中、失败、重试、取消、超时、权限拒绝、浏览器不支持等状态分别设计用例。

### 4. 模拟真实使用场景

提词器必须模拟远距离阅读、直播插话、快捷键操作、弱网、误触和长稿滚动，而不只做表单点击测试。

## 上线验收边界

| 条件 | 要求 |
|------|------|
| **P0 Bug** | 必须清零，不允许带入上线 |
| **P1 Bug** | 核心链路相关必须清零，非核心需有明确规避方案 |
| **核心链路** | 至少完成一次端到端回归并通过 |
| **兼容性** | Chrome / Edge 必测，Safari 对 Web API 降级提示必测 |
| **安全合规** | 涉及素材、语音、内容发布、API Key 的变更必须通过对应检查 |
| **异常路径** | 文件失败、生成失败、任务失败、权限拒绝必须有可见提示 |

## 自动化测试优先级

| 优先级 | 适合自动化的场景 |
|--------|------------------|
| **高** | 首页入口、AI 生成表单校验、提词器基础播放、任务状态展示 |
| **中** | 文件导入、复制、响应式冒烟、错误提示展示 |
| **低** | 视觉细节、真实语音识别、直播临场互动、复杂浏览器权限 |

自动化覆盖稳定高频路径，手工测试保留真实直播、语音、兼容和体验判断。
