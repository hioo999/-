## 合规评审方法论

### 1. 先识别行业和平台

教育、医美、健康、金融、招商加盟等行业默认高风险；抖音、小红书、视频号、B站等平台规则也会影响表达边界。

### 2. 再判断内容类型

口播文案、直播话术、封面标题、短剧剧情、用户案例、价格机制和效果承诺的风险不同，不能用同一套标准粗略判断。

### 3. 检查承诺强度和证据支撑

凡是涉及收益、效果、治愈、通过率、销量、排名、权威背书的数据或承诺，都要检查是否有证据支撑。

### 4. 给出可替代表达

合规评审不只指出风险，还要给出低风险且保留转化力的改写建议。

---

## 风险等级标准

| 等级 | 定义 | 处理方式 |
|------|------|----------|
| **低风险** | 表达客观、无明显承诺或侵权 | 可发布，建议保留审慎表述 |
| **中风险** | 存在夸张、模糊承诺或证据不足 | 修改后发布 |
| **高风险** | 涉及绝对化、收益承诺、效果保证、敏感行业违规 | 必须修改并复审 |
| **禁止发布** | 涉及违法、侵权、虚假宣传、平台明确禁限内容 | 阻断发布，不建议生成或传播 |

## 内容审核输出模板

```markdown
【审核对象】口播文案 / 直播话术 / 标题封面 / 短剧脚本 / Prompt

【适用行业】行业名称

【发布平台】抖音 / 小红书 / 视频号 / B站 / 其他

【总体风险等级】低 / 中 / 高 / 禁止发布

【主要风险点】
- 原文：摘录风险表达
- 问题：说明违规或高风险原因
- 建议：给出替代表达

【是否建议发布】可发布 / 修改后发布 / 复审后发布 / 不建议发布
```

## Prompt 合规约束模板

```text
生成内容必须遵守以下限制：
1. 不使用“最、第一、唯一、百分百、保证、稳赚、包过”等绝对化或结果承诺表达。
2. 不编造数据、案例、资质、用户反馈和权威背书。
3. 不贬损竞品，不攻击特定人群，不制造歧视或低俗冲突。
4. 涉及教育、医美、健康、金融、招商加盟等行业时，必须使用审慎表达。
5. 对可能受个体差异影响的效果，使用“有助于、可能、在特定场景下、需结合实际情况”等表述。
```

## 合规验收边界

| 场景 | 验收要求 |
|------|----------|
| **AI 生成内容** | 不含明显虚假、绝对化、侵权和平台禁限内容 |
| **直播带货话术** | 不承诺效果、收益、最低价、限时虚假优惠 |
| **封面标题** | 不制造误导性前后对比，不夸大结果 |
| **短剧脚本** | 不低俗、不歧视、不恶意贬损竞品或群体 |
| **高风险行业** | 必须使用审慎表达，必要时提示人工复审 |
| **Prompt 模板** | 内置合规禁止项和改写规则 |
