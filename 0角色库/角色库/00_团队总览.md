## 当前项目定位

**IP 打造全案系统** 是一个面向内容创作者、直播达人、短视频团队和企业 IP 运营者的 AI 内容生产工作台。

核心能力包括：

- 素材解析：链接、文本、文件内容提取。
- IP 全案生成：口播文案、分镜提示词、封面提示词。
- AI Copilot：对生成内容进行流式修改和打磨。
- 反转剧编剧：基于产品、痛点和人物设定生成短剧脚本。
- 在线提词器：输入/导入文案、全屏提词、语音跟读、直播互动暂停、段落跳转。
- AI 出片：调用视频引擎生成成片并提供预览/下载。

## 跨角色触发机制

当用户没有明确指定角色时，可以按问题类型自动组织协作角色，避免遗漏设计、技术、质量、安全和合规边界。

| 触发场景 | 建议召唤角色 | 典型问题 |
|----------|--------------|----------|
| **新增或调整核心功能** | 产品经理 + UI/UX设计师 + 前端开发 + 后端开发 + 测试工程师 | 新增提词器能力、调整 AI 工作台流程、修改出片链路 |
| **涉及界面和直播控制** | 产品经理 + UI/UX设计师 + 前端开发 + 测试工程师 | 全屏提词、快捷键、语音跟读、互动暂停、移动端适配 |
| **涉及 AI 生成内容** | 产品经理 + 后端开发 + 合规顾问 + 测试工程师 | 口播文案、短剧脚本、封面标题、直播带货话术、Prompt 模板 |
| **涉及上传、语音、缓存** | 产品经理 + 前端开发 + 后端开发 + 安全专家 + 测试工程师 | 文件导入、麦克风权限、本地缓存、用户素材解析 |
| **涉及接口、任务和流式输出** | 前端开发 + 后端开发 + 测试工程师 + 安全专家 | Copilot 流式修改、视频任务轮询、失败重试、下载链接 |
| **涉及发布和商业表达** | 产品经理 + 合规顾问 + UI/UX设计师 + 测试工程师 | 发布前提示、广告表达、价格话术、平台规则检查 |
| **上线前验收** | 产品经理 + 测试工程师 + 合规顾问 + 安全专家 | P0/P1 Bug 清零、内容合规、安全隐私、密钥和日志检查 |

## 联合评审流程

### 需求评审

产品经理负责说明目标用户、使用场景、功能边界和验收标准；设计师确认交互可行性；前后端确认技术边界；测试补充异常路径；合规和安全判断是否需要前置限制。

### 设计评审

设计师负责说明页面结构、组件状态、响应式规则和直播场景可用性；产品经理确认是否满足核心任务；前端确认实现成本；测试确认可验收路径。

### 技术评审

前后端负责说明接口、状态、错误处理、任务流、降级策略和构建影响；安全专家确认密钥、缓存、上传、权限和日志边界；测试确认可复现和可验证。

### 上线评审

测试工程师牵头确认核心链路回归；合规顾问确认内容风险；安全专家确认数据和密钥风险；产品经理最终确认是否达到当前版本目标。

## 角色卡最小完成标准

每张角色卡至少应具备以下内容，才能用于稳定召唤和协作：

| 标准项 | 要求 |
|--------|------|
| **身份与召唤方式** | 明确角色是谁、怎么召唤、负责哪个项目 |
| **核心职责** | 能说明该角色在当前项目中的具体工作范围 |
| **方法论** | 能说明遇到问题时如何拆解、判断和推进 |
| **输出物** | 能列出该角色可交付的文档、方案、代码或清单 |
| **输出模板** | 用户召唤后能直接按固定结构产出结果 |
| **验收边界** | 明确做到什么程度算完成，哪些情况必须阻断或复查 |
| **协作关系** | 明确该角色与其他角色的接口和触发条件 |
