# 生产中心重构排期与任务分发

## 1. 产品判断

生产中心重构现在应该做，而且应作为当前平台化重构的主线任务推进。原因是当前生产中心仍然偏工具集合和短视频生成，无法承接 `docs/重点需求.md` 中定义的核心闭环：

```text
IP 项目 -> 内容选题 -> 平台内容 -> 素材 / 资产 / 任务 / 发布记录
```

本排期以 `docs/plan-production-center-restructure.md` 为执行依据，目标是把当前 `CopilotWorkspace.vue` 中的生产中心从“即时生成工具页”改造为“项目级生产驾驶舱”。

## 2. 总目标

在本轮排期完成后，用户应能在生产中心完成以下闭环：

```text
选择或创建 IP 项目
-> 选择或创建内容选题
-> 添加主题、链接、原文或素材
-> 生成公众号文章
-> 编辑排版和生成封面
-> 发送公众号草稿箱
-> 查看任务、资产、生成记录和草稿记录
```

同时为小红书、抖音/视频号口播、短大片、剧本短视频预留同一套上下文和扩展入口。

## 3. MVP 范围

### 3.1 必须完成

| 模块 | MVP 范围 |
|---|---|
| 生产中心壳 | 新建独立 `ProductionCenter.vue`，不继续堆在 `CopilotWorkspace.vue` |
| 项目上下文 | 支持选择、创建 IP 项目 |
| 选题上下文 | 支持选择、创建内容选题，选题归属项目 |
| 素材入口 | 支持主题、链接、粘贴原文三类输入，并挂到当前选题 |
| 公众号生产 | 将现有公众号生成、编辑、封面、草稿发送能力接入生产中心 |
| 任务侧栏 | 展示当前选题下的内容生成、图片生成、草稿发送任务 |
| 资产侧栏 | 展示当前选题下的文章、封面、插图、发布记录等资产 |
| 导航调整 | `生产中心` 指向新生产中心，旧工具保留兼容入口 |
| 验收测试 | 覆盖项目、选题、公众号生成、草稿发送、任务和资产展示 |

### 3.2 应该完成

| 模块 | 范围 |
|---|---|
| 生产概览 | 展示当前项目、选题、平台内容、任务统计和最近资产 |
| 小红书/口播入口 | 复用现有 `PlatformContentStudio.vue` 能力，接入为生产中心平台面板 |
| 生成记录 | 展示模板、模型、原始返回和解析结果摘要 |
| 失败重试 | 当前任务失败后可从生产中心侧栏重试 |
| 首页入口 | 首页快捷入口进入新生产中心，并弱化旧 IP 工具页入口 |

### 3.3 可以延后

| 模块 | 延后原因 |
|---|---|
| 完整资产库独立页面 | 先在生产中心侧栏闭环，再做全局资产库 |
| 完整任务中心独立页面 | 先做当前选题任务列表，再做全局任务中心 |
| 短大片完整视频闭环 | 已有 AIP 能力可保留，先作为高级视频入口 |
| 剧本短视频完整闭环 | 先保留角色和分镜资产基础，后续独立阶段推进 |
| 复杂权限和团队协作 | 当前先保留管理员/普通用户基础区分 |

### 3.4 暂不做

| 模块 | 原因 |
|---|---|
| 自动群发公众号 | 第一阶段只发送草稿箱，避免误发和合规风险 |
| 小红书自动发布 | PRD 第一版不承诺自动发布 |
| 抖音/视频号自动发布 | PRD 第一版只预留配置口 |
| 复杂审批流 | 不影响第一阶段闭环 |
| 大规模工作流编排器 | 当前先按平台面板和统一任务模型落地 |

## 4. 总体排期

本次重构建议按 6 个 Sprint 推进，每个 Sprint 以 3 到 5 个工作日为单位。若人员充足，后端底座、前端壳、UI 设计可并行推进。

| Sprint | 目标 | 主要交付 | 建议周期 | 完成标准 |
|---|---|---|---|---|
| Sprint 0 | 需求冻结与方案对齐 | 信息架构、接口清单、字段确认、验收清单 | 1-2 天 | 产品、设计、前后端、测试对范围无异议 |
| Sprint 1 | 生产中心壳和上下文 | `ProductionCenter.vue`、项目/选题选择创建、路由导航接入 | 3-5 天 | 可进入新生产中心并选择项目和选题 |
| Sprint 2 | 素材与生产上下文聚合 | 主题/链接/原文输入、生产上下文聚合接口、选题概览 | 3-5 天 | 素材可归属当前选题并用于生成 |
| Sprint 3 | 公众号闭环接入 | 公众号生成、编辑、封面/插图、草稿发送接入生产中心 | 5-7 天 | 可从生产中心完成公众号草稿箱闭环 |
| Sprint 4 | 任务和资产侧栏 | 当前选题任务列表、资产列表、生成记录、失败重试 | 3-5 天 | 生成、图片、草稿任务和资产可追踪 |
| Sprint 5 | 多平台入口与旧能力收口 | 小红书/口播入口接入，高级视频入口迁移，首页导航调整 | 3-5 天 | 旧生产中心不再作为主入口，新入口可覆盖主流程 |
| Sprint 6 | 验收、回归和上线准备 | E2E、接口测试、异常路径、文档和上线检查 | 2-4 天 | 验收清单全部通过，遗留问题有明确归档 |

## 9. 阻塞风险与处理

| 风险 | 影响 | 预案 | 决策人 |
|---|---|---|---|
| 现有接口字段不统一 | 前端生产中心联调变慢 | 先做 `/api/production/context` 聚合接口屏蔽差异 | BE、PM-小P |
| `CopilotWorkspace.vue` 过大难拆 | 前端重构风险高 | 不在原文件内大改，先新建壳，逐步迁移能力 | FE、PM-小P |
| 公众号真实接口受 IP 白名单影响 | 草稿发送验收受阻 | 提供测试连接和可解释错误，保留 mock/失败记录测试 | BE、QA |
| 资产和任务历史数据不完整 | 侧栏展示不稳定 | MVP 先展示新流程产生的数据，历史数据兼容延后 | PM-小P |
| 多平台范围膨胀 | 拖慢公众号闭环 | Sprint 3 前只做公众号，其他平台只预留 tab 和入口 | PM-小P |
| 密钥或素材权限风险 | 上线阻塞 | 安全专家提前介入账号和素材访问设计 | Security、BE |

## 10. 验收清单

### 10.1 产品验收

- 用户可以进入新生产中心。
- 用户可以创建或选择 IP 项目。
- 用户可以在项目下创建或选择内容选题。
- 用户可以在选题下输入主题、链接或原文素材。
- 用户可以基于当前选题生成公众号文章。
- 用户可以编辑公众号标题、摘要、作者和正文。
- 用户可以生成或上传公众号封面。
- 用户可以选择公众号账号并发送到草稿箱。
- 用户可以看到当前选题下的任务状态。
- 用户可以看到当前选题下的资产。
- 用户可以看到草稿发送记录。
- 旧生产中心不再误导用户从短视频工具开始主流程。

### 10.2 技术验收

- 新生产中心不继续依赖 `CopilotWorkspace.vue` 中旧 `workspaceMode === 'ip'` 的大段模板结构。
- 生产上下文只围绕 `currentProjectId`、`currentTopicId`、`currentPlatform`、`currentContentId` 传递。
- 平台内容、任务、资产、生成记录都能关联到项目和选题。
- 任务失败保存错误码、错误信息和原始响应摘要。
- 生成记录保存提示词模板、版本、模型、参数和原始返回摘要。
- AppSecret 和 API Key 不明文返回前端。
- 关键接口有测试覆盖。

### 10.3 测试验收

- 项目创建、选择、刷新恢复通过。
- 选题创建、选择、切换隔离通过。
- 素材输入和归属通过。
- 公众号生成成功路径通过。
- 公众号生成失败路径通过。
- 封面缺失拦截通过。
- 草稿发送成功路径通过。
- 草稿发送失败路径通过。
- 任务轮询和失败重试通过。
- 资产列表刷新通过。
- 普通用户无法查看敏感密钥通过。

## 11. 完成定义

本轮重构视为完成，需要同时满足以下条件：

1. 新生产中心成为主导航中的默认生产入口。
2. 用户可以围绕一个 IP 项目和一个内容选题完成公众号草稿箱闭环。
3. 公众号生成、封面、草稿发送均产生可追踪任务。
4. 文章、封面、插图、草稿记录均进入当前选题资产视图。
5. 生成记录可以追溯模板、模型、参数和原始返回摘要。
6. 小红书、口播、高级视频入口在新生产中心中有明确占位或基础接入，不再割裂于主流程之外。
7. 旧 `CopilotWorkspace.vue` 生产中心不再承担主生产入口职责。
8. 产品、测试、安全的 P0 验收全部通过。

## 13. 小P执行结论

本次排期的核心原则是：先闭环，再扩平台；先让公众号在新生产中心跑通，再把小红书、口播、短大片和剧本短视频接入同一套项目、选题、任务和资产模型。

所有团队的任务都围绕一个目标收敛：

```text
用户不再面对一堆分散工具，而是在一个生产中心里围绕一个 IP 项目和一个选题完成内容生产、任务追踪、资产沉淀和发布记录。
```
