# ip-system Documentation

Documentation for the IP creation workspace.

## Getting Started

1. Backend code lives in `backend/`.
2. Frontend code lives in `frontend/`.
3. Run Harness checks from the project root: `harness validate`.
4. Keep local dependencies, outputs, virtual environments, and databases out of product source.
