正确生产中心总流程 最终应该是这个逻辑：

1. 用户进入生产中心
2. 选择或创建 IP 项目
3. 选择或创建内容选题
4. 添加素材：主题、链接、原文、文件、图片、视频
5. 素材解析任务进入任务中心
6. 解析结果沉淀为 source_material
7. 用户选择目标平台
8. 系统根据平台、场景、步骤读取已配置的提示词模板和模型
9. 用户生成平台内容
10. 内容生成任务进入任务中心
11. 生成结果保存为 platform_content
12. 原始返回、模型快照、模板快照保存为 generation_record
13. 封面、插图、视频、分镜等保存为 assets
14. 用户编辑平台内容
15. 公众号进入草稿箱发布，小红书/口播进入复制导出或提词器
16. 发布动作进入任务中心
17. 成功后保存 publish_record
18. 当前选题状态更新

## 新用户任务化入口

生产中心需要先让用户选择“今天要完成什么”，再进入项目、选题、素材和生产模块。推荐入口如下：

| 任务入口 | 推荐路径 |
|---|---|
| 生成一条口播视频 | 主题/素材 -> 口播文案 -> 提词器/出片 |
| 做一篇公众号文章 | 素材 -> 二创长文 -> 公众号排版 -> 草稿箱 |
| 准备一场直播话术 | 产品/活动 -> 直播脚本 -> 在线提词器 |
| 生成一条反转短剧 | 产品/痛点 -> 剧情脚本 -> 分镜 -> 高级视频 |

生产中心首页不应优先暴露内部模块名，而应先展示任务卡片和推荐生产顺序：

```text
选择任务
-> 建立 IP 档案/项目目标
-> 输入素材
-> 选择模板或平台
-> 生成内容
-> 修改定稿
-> 提词录制 / AI 出片 / 公众号排版
-> 保存项目 / 发布记录
```

具体 PRD 见 `docs/prd-production-center-guided-workflow.md`。

## 首单生产向导

新用户第一次进入生产中心时，应提供一个页面内 3 步向导：

```text
选任务
-> 用示例填素材
-> 点下一步
```

每个任务需要提供一个可直接填入的示例：

| 任务入口 | 示例 |
|---|---|
| 生成一条口播视频 | 如何用 AI 提升个人 IP 内容生产效率 |
| 做一篇公众号文章 | 从一篇资料整理成企业 IP 长文 |
| 准备一场直播话术 | 618 活动直播开场和促单话术 |
| 生成一条反转短剧 | 客户不信任 AI 工具，最后被效率反转 |

“用示例开始”会填充项目名、账号定位、选题名称、素材标题和主题/原文，让用户先跑通一遍生产链路。

## 独立工具入口

提示词工具需要单独列出来。它用于管理提示词分类、模板、版本和规则，是内容生成时读取的配置工具，不属于“选择任务 -> 输入素材 -> 生成内容 -> 交付发布”的生产链步骤。

## 下一步动作提示

生产中心顶部需要始终告诉用户“当前该做什么”：

| 当前状态 | 下一步 |
|---|---|
| 没有 IP 项目 | 创建 IP 项目 |
| 有项目但没有选题 | 创建内容选题 |
| 有选题但没有已保存素材 | 输入并保存素材 |
| 有素材但没有平台内容 | 进入对应生产模块 |
| 已有平台内容 | 检查提词、出片、公众号草稿箱或资产记录 |

这个提示不是替代下方表单，而是把表单和模块 tab 组织成一条清晰主路径。

素材步骤以 `source_material` 是否已沉淀为完成标准。用户只填写了主题或原文但没有保存时，仍然停留在“输入并保存素材”。
