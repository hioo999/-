# PRD：统一生成配置侧栏与视频 AIP 链路

## 1. 产品判断

本需求应该做，但不能把口播、封面、图片、视频拆成多个割裂入口。正确做法是把它们统一成 IP 全案工作台里的“生成配置侧栏”：左侧/中间承接素材和生成结果，右侧统一选择后台模板、模型、比例、时长、风格和用户补充提示词。

视频板块需要从“生成一个视频提示词”升级为“视频 AIP 流水线”。AIP 不是单步按钮，而是把参考图标准化、多视图一致性、分镜图、视频提示词和视频任务串起来。

## 2. 功能名称

统一生成配置侧栏与视频 AIP 链路。

## 3. 需求背景

当前 IP 全案工作台已经有素材解析、口播生成、分镜提示词、封面提示词和短视频工作流能力，但还存在以下问题：

| 问题 | 影响 |
|---|---|
| 提示词配置分散 | 用户生成口播、封面、视频时需要在不同区域反复填写要求 |
| 模板不可运营 | 前端硬编码会导致提示词无法持续优化 |
| 模型配置不灵活 | 新增大模型需要改代码，不利于测试不同供应商 |
| 视频链路太短 | 产品大片和短剧都需要先做参考图一致性，再生成分镜和视频 |
| 图片/视频一致性不可控 | 直接生成视频容易出现产品变形、人物串脸、包装文字错误 |
| 提示词分段误伤小数点 | `opus4.8`、模型版本号、小数参数不应被拆成两段 |
| 提示词不能沉淀为素材 | 分镜提示词、封面提示词和 AIP 步骤提示词需要一键保存到素材库复用 |

## 4. 核心目标

用户上传或输入素材后，可以在右侧配置栏完成以下设置：

| 内容类型 | 右侧可配置内容 |
|---|---|
| 口播文案 | 提示词分类、提示词模板、文本模型、平台、风格、补充要求 |
| 封面图片 | 封面模板、人物/产品参考图、标题、副标题、比例、图片模型 |
| 人物图片 | 人物参考图、三视图/四视图模板、场景、姿态、比例、图片模型 |
| 产品视频 | 产品主体清理模板、三/四视图模板、九/三十六宫格分镜模板、视频模型 |
| 人物短剧 | 多人物四视图模板、剧情模板、图片分镜模板、视频模型 |

后台可以维护：

| 后台对象 | 能力 |
|---|---|
| 提示词分类 | 按文案、封面、人物图、视频链路分类 |
| 提示词模板 | 新增、编辑、停用、排序、默认模板、版本号 |
| 大模型配置 | 名称、类型、API Key、Base URL、模型 ID、启停、默认模型 |
| 生成历史 | 保存模板、模型、版本和参数快照 |

## 5. 右侧生成配置侧栏

侧栏不只是一个提示词输入框，而是生成控制台。

### 5.1 侧栏结构

| 区块 | 内容 |
|---|---|
| 口播文案 | 文案模板、文本模型、模板说明、用户补充提示词 |
| 封面/人物图片 | 封面模板、人物图/产品图引用、比例、标题、图片模型 |
| 视频 AIP 链路 | 链路类型、视频模板、比例、时长、视频模型、链路步骤 |
| 用户补充提示词 | 用户自由填写本次生成要求 |
| 生成按钮 | 按当前配置生成全案 |

### 5.3 提示词展示与素材沉淀

提示词展示和保存需要遵守以下规则：

| 规则 | 说明 |
|---|---|
| 不按普通句号硬切分 | 英文句点只有在不是数字小数点时才可作为断句依据，`opus4.8`、`V1.5` 等应保持完整 |
| 保留原提示词语义 | 分镜、封面、视频 AIP 步骤提示词展示时不得因自动换行破坏模型名、版本号、参数值 |
| 一键保存到素材 | 视频提示词、分镜提示词、封面提示词、单个 AIP 步骤提示词都应可保存为 `source_material` 资产 |
| 批量保存 | 视频 AIP 链路支持把全部步骤提示词保存为一个总包素材，并同时保存每个步骤提示词 |
| 保存元数据 | 素材元数据需包含来源、提示词正文、角色类型和步骤 key，方便后续复用与追溯 |
| 支持归属 | 保存提示词素材时可选择项目和选题；未选择时保存到个人素材库 |
| 自动去重 | 系统根据提示词正文、角色类型和步骤 key 生成哈希，同一份提示词不重复保存 |
| 素材库可读 | `source_material` 类型的提示词素材应支持筛选、内联预览全文、复制、回填到素材输入区 |

### 5.4 用户可改与不可改边界

| 类型 | 规则 |
|---|---|
| 可改 | 用户补充提示词、比例、时长、风格、标题、模型选择 |
| 可看 | 模板名称、模板说明、输出结构、示例 |
| 不直接暴露 | 后台系统提示词、合规约束、安全提示词、模型 API Key |

## 6. 视频 AIP 链路一：产品宣传大片

### 6.1 适用场景

适合产品广告、TVC、带货短片、饮品、香水、护肤品、包装食品、电子产品、课程产品等。

### 6.2 输入

| 输入 | 说明 |
|---|---|
| 产品图片 | 用户上传产品图，最好是包装清晰、主体完整 |
| 产品信息 | 产品名、卖点、使用场景、目标人群 |
| 视频目标 | 种草、成交、品牌宣传、直播预热 |
| 画面参数 | 比例、时长、风格、平台 |

### 6.3 链路步骤

| 步骤 | 名称 | 目标 | 输出 |
|---|---|---|---|
| 1 | 主体清理 | 从用户产品图中提取完整主体，去掉杂乱背景 | 主体清理提示词/主体参考图 |
| 2 | 三视图/四视图 | 生成产品正面、侧面、背面、细节视图，建立一致性锚点 | 产品多视图提示词/多视图参考图 |
| 3 | 九宫格/三十六宫格 | 根据卖点和风格生成可拍摄分镜图 | 分镜提示词、镜头功能、画面说明 |
| 4 | 最终视频提示词 | 综合主体图、多视图、分镜、用户要求生成视频模型提示词 | 可提交给视频模型的最终提示词 |
| 5 | 视频任务 | 调用视频模型生成短视频 | 视频任务状态、预览、下载 |

### 6.4 一致性规则

产品链路必须保持：产品外形、包装结构、品牌标识、标签文字、颜色、材质、比例、反光、纹理一致。禁止改字、加字、改包装、变形、生成相似但不是原产品的包装。

### 6.5 右侧模板

| 模板类型 | 示例 |
|---|---|
| 主体清理模板 | 白底产品主体清理、透明背景主体图、商业棚拍主体图 |
| 多视图模板 | 三视图、四视图、包装细节图、手持产品图 |
| 分镜模板 | 九宫格种草、九宫格高级 TVC、三十六宫格大片分镜 |
| 视频模板 | 15 秒产品大片、直播预热视频、品牌质感短片 |

## 7. 视频 AIP 链路二：人物短剧

### 7.1 适用场景

适合反转剧、剧情短片、人物 IP 短剧、多人对话、品牌剧情广告。

### 7.2 输入

| 输入 | 说明 |
|---|---|
| 多人物图片 | 用户上传 1 到 N 个角色图片 |
| 人物设定 | 角色名、身份、性格、关系、口头禅 |
| 剧情信息 | 冲突点、反转点、产品/观点、结尾动作 |
| 视频参数 | 平台、比例、时长、风格、镜头节奏 |

### 7.3 链路步骤

| 步骤 | 名称 | 目标 | 输出 |
|---|---|---|---|
| 1 | 多角色四视图 | 每个人物分别生成一致性四视图 | 角色四视图提示词/参考图 |
| 2 | 剧情提示词 | 根据人物关系和冲突点生成剧本 | 剧情脚本、台词、反转结构 |
| 3 | 图片分镜图 | 把剧本拆成镜头，并生成每镜图片提示词 | 分镜图提示词、人物出场、动作、表情 |
| 4 | 最终视频提示词 | 综合剧本、角色四视图、图片分镜生成视频提示词 | 可提交给视频模型的短剧提示词 |
| 5 | 视频任务 | 调用视频模型生成短剧视频 | 视频任务状态、预览、下载 |

### 7.4 一致性规则

人物短剧链路必须保持：脸型、五官、发型、发色、肤色、体型、服装、配饰、年龄感、气质一致。禁止换脸、串脸、改年龄、改服装、角色关系混乱、多余肢体。

### 7.5 右侧模板

| 模板类型 | 示例 |
|---|---|
| 人物四视图模板 | 正面/侧面/背面/半身细节、角色设定卡 |
| 剧情模板 | 30 秒反转剧、职场冲突、产品植入、双人对话 |
| 图片分镜模板 | 九宫格剧情分镜、三十六宫格连续动作分镜 |
| 视频模板 | 30 秒短剧、15 秒反转短片、人物 IP 连续剧 |

## 8. 后台模板类型

| template_type | 用途 |
|---|---|
| text_script | 口播文案 |
| image_cover | 封面图片 |
| image_character | 人物图、人物四视图 |
| video_clip | 视频链路、分镜和最终视频提示词 |

## 9. 后台模型类型

| model_type | 用途 |
|---|---|
| text | 口播、剧情、分镜、提示词生成 |
| image | 主体清理、封面图、人物四视图、分镜图 |
| video | 最终视频生成 |
| multimodal | 可同时理解图片和文本的模型 |

MVP 添加模型采用两种模式：

| 模式 | 字段 |
|---|---|
| 快速添加 | 模型名称、模型类型、API Key |
| 高级添加 | 模型名称、模型类型、供应商、API Key、Base URL、模型 ID、超时、重试 |

## 11. 当前实现边界

本阶段先完成“配置和提示词链路”：用户可以在右侧选择模板、模型和参数，生成口播文案、封面提示词、视频提示词，并在历史中记录使用的配置。

真实图片生成和视频生成需要后续接入具体模型能力，包括主体抠图、四视图图片、九/三十六宫格图片、视频任务提交、任务状态轮询、预览和下载。没有接入真实模型前，产品界面不得暗示“已经自动出图/出视频”。

## 12. 验收标准

| 模块 | 验收标准 |
|---|---|
| 右侧配置栏 | 工作台内可直接选择文案、封面、视频模板和模型 |
| 模板后台 | 模板支持 text_script、image_cover、image_character、video_clip 类型 |
| 模型后台 | 管理员可配置名称、类型、API Key、Base URL、模型 ID，前端不暴露明文密钥 |
| 口播生成 | 生成请求能携带文案模板和文本模型配置 |
| 封面提示词 | 生成请求能携带封面模板、比例、标题和图片模型配置 |
| 视频提示词 | 生成请求能携带视频模板、比例、时长、AIP 链路类型和视频模型配置 |
| 提示词分段 | 模型版本号或小数值中的 `.` 不会导致提示词被拆段，例如 `opus4.8` 保持在同一段 |
| 提示词保存 | 分镜、封面、视频 AIP 步骤提示词可一键保存到素材库，资产类型为 `source_material` |
| 归属和去重 | 提示词素材保存时可绑定项目/选题，并能拦截重复保存 |
| 素材复用 | 生产中心资产库可查看、复制、应用提示词素材 |
| 批量总包 | 视频 AIP 全链路可保存为单个提示词总包素材，同时按步骤保存单个提示词素材 |
| 资产筛选 | 生产中心资产库支持按“提示词素材”筛选 |
| 内联预览 | 提示词素材在资产库内展开查看，不强制打开新窗口 |
| 产品 AIP | PRD 和模板明确主体清理、三/四视图、九/三十六宫格、视频提示词步骤 |
| 短剧 AIP | PRD 和模板明确多人物四视图、剧情、图片分镜、视频提示词步骤 |
| 历史追踪 | 生成历史保存模板 ID、模型 ID 和生成参数快照 |

### 13.3 人工验收路径

1. 后端启动：在 `backend/` 运行 `uvicorn main:app --host 0.0.0.0 --port 8000 --reload`。
2. 前端启动：在 `frontend/` 运行 `npm run dev`。
3. 登录管理员账号，进入提示词管理页。
4. 创建或选择一个口播模板，确认模板正文只在管理页可见。
5. 进入 IP 全案工作台，输入主题，选择口播模板、封面模板、视频模板和模型配置。
6. 点击“按当前配置生成全案”，确认生成结果包含口播文案、视频提示词和封面提示词。
7. 使用 Copilot 修改口播文案，导出当前文案，并发送到提词器。
8. 回到提示词管理页，确认模板的生成次数、编辑率、定稿率、提词转化率发生变化。
9. 尝试保存包含疑似密钥或“ignore previous instructions”的模板，确认前端提示风险且后端阻断保存。
