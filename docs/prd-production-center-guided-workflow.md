# PRD: 生产中心任务化引导与流程重组

## 1. 功能名称

生产中心任务化引导与流程重组。

目标是在现有生产中心上增加“先选任务、再按步骤生产”的新手入口和首单生产向导，把内容交付能力组织成生产流水线；提示词管理作为独立工具单独列出，不并入生产链步骤。

## 2. 需求背景

当前生产中心已经具备 IP 项目、内容选题、素材输入、公众号、小红书/口播、提词器、高级视频、提示词工具、任务和资产侧栏等基础能力，但新用户进入后仍需要先理解多个内部模块，容易不知道第一步该做什么。

用户真实任务不是“打开某个工具”，而是完成一次内容交付，例如生成一条口播视频、做一篇公众号文章、准备直播话术或生成一条反转短剧。因此生产中心需要在保留现有功能的基础上增加任务入口和生产顺序提示。

## 3. 目标用户

| 用户 | 场景 |
|---|---|
| 内容创作者 | 输入主题或素材，快速生成口播稿并进入提词录制 |
| 企业 IP 运营者 | 把观点、案例或资料二创为公众号文章并发送草稿箱 |
| 直播达人 | 围绕商品、活动或直播主题准备开场、促单和互动话术 |
| 短视频团队 | 从产品、痛点和角色出发生成反转剧脚本与分镜 |

## 4. 核心目标

用户首次进入生产中心时，不需要理解所有模块名，而是先回答“今天要完成什么内容”。系统根据任务给出推荐生产顺序，并提供“用示例开始”，把现有 IP 项目、选题、素材、生成、打磨、提词、出片和发布能力串成一条明确路径。

## 5. 产品判断

生产中心需要拆分，但不是继续拆更多一级菜单，而是拆成任务阶段：

```text
任务入口层
-> 项目设定层
-> 素材输入层
-> 内容生成层
-> 打磨定稿层
-> 交付发布层
```

这条流程应成为生产中心的默认引导。现有 IP 全案、AI Copilot、提词器、AI 出片、公众号排版等生产能力继续保留，并被任务流程重新组织。提示词工具只负责模板和分类配置，作为生成配置被调用，不作为生产链中的一个阶段。

## 6. 用户故事

1. 作为新用户，我希望进入生产中心后先选择“生成口播视频”或“做公众号文章”，这样我不用先理解所有工具。
2. 作为内容创作者，我希望系统告诉我先建立 IP 项目，再创建选题，再输入素材，避免不知道下一步。
3. 作为运营人员，我希望不同任务能自动推荐下一步入口，例如公众号进入排版草稿箱，口播进入提词器。
4. 作为团队负责人，我希望所有内容、素材、任务和资产仍然归属到当前项目和选题，方便后续追踪。

## 7. 主流程

```text
进入生产中心
-> 选择任务类型
-> 选择或创建 IP 项目
-> 选择或创建内容选题
-> 输入主题、链接、文字、文件或媒体素材
-> 选择模板或目标平台
-> 生成内容
-> 修改定稿
-> 提词录制 / AI 出片 / 公众号排版 / 草稿箱发布
-> 保存项目资产与发布记录
```

## 8. 任务入口

| 任务入口 | 默认目标 | 推荐后续模块 | 示例开始 |
|---|---|---|---|
| 生成一条口播视频 | 主题或素材生成口播稿 | 小红书/口播、提词器、AI 出片 | 如何用 AI 提升个人 IP 内容生产效率 |
| 做一篇公众号文章 | 素材二创为公众号图文 | 公众号闭环、草稿箱发布 | 从一篇资料整理成企业 IP 长文 |
| 准备一场直播话术 | 商品、活动或观点转直播话术 | 小红书/口播、提词器 | 618 活动直播开场和促单话术 |
| 生成一条反转短剧 | 产品、痛点和角色转剧情脚本 | 高级视频、分镜和出片 | 客户不信任 AI 工具，最后被效率反转 |
| 提示词工具 | 管理提示词分类、模板、版本和规则 | 独立工具入口，不进入生产链 | 不提供生产示例 |

## 9. 页面与组件

| 区域 | 说明 |
|---|---|
| 任务卡片区 | 位于生产中心顶部，先展示 4 个用户能理解的生产目标 |
| 首单生产向导 | 展示 3 步轻量路径：选任务、用示例填素材、点下一步 |
| 推荐流程区 | 展示“选择任务 -> 建立 IP 档案 -> 创建选题 -> 输入素材 -> 生成 -> 交付”的步骤 |
| 下一步动作区 | 根据当前状态提示用户“现在该做什么”，并提供可直接执行的主按钮 |
| 项目设定区 | 沿用现有 IP 项目选择和创建能力 |
| 选题设定区 | 沿用现有内容选题选择和创建能力 |
| 素材输入区 | 沿用主题、链接、原文输入，后续扩展文件、图片、视频 |
| 生产模块区 | 保留现有 5 个模块 tab，不新增平行入口 |
| 独立工具区 | 单独列出提示词工具，说明其是后台配置工具，不参与生产链步骤 |
| 任务/资产侧栏 | 保留生成进度、资产库和最近生成记录 |

## 10. 字段与规则

| 字段 | 规则 |
|---|---|
| selectedTask | 用户当前选择的生产任务，默认可为口播视频 |
| targetTab | 根据任务推荐进入公众号、小红书/口播、提词器或高级视频 |
| defaultInputMode | 根据任务推荐主题、链接或原文输入，但不强制覆盖用户已填内容 |
| exampleTitle | 每个任务的示例选题标题，用于首单生产向导 |
| exampleMaterial | 每个任务的示例素材正文，用于一键填充主题或原文 |
| targetPlatforms | 根据任务预设目标平台，用于选题和平台内容生成 |
| workflowStepState | 根据项目、选题、素材、内容、任务资产状态显示已完成/当前步骤 |
| nextWorkflowAction | 根据当前状态返回下一步动作，支持创建项目、创建选题、保存素材、进入生产模块、查看交付记录 |
| hasSavedMaterial | 只根据已沉淀的 `source_material` 判断素材步骤完成；用户仅填写但未保存时仍提示保存素材 |

### 10.1 下一步动作规则

| 当前状态 | 动作提示 | 主按钮 |
|---|---|---|
| 未选择或创建项目 | 当前该做：建立 IP 项目 | 创建 IP 项目 |
| 已有项目但没有选题 | 当前该做：创建内容选题 | 创建内容选题 |
| 已有选题但没有素材 | 当前该做：输入并保存素材 | 保存素材 / 先填写素材 |
| 已有素材但没有平台内容 | 当前该做：进入内容生成 | 进入当前任务对应模块 |
| 已有平台内容 | 当前该做：检查交付出口 | 查看交付记录 |

这个动作区的目标是减少新用户决策成本。用户可以继续使用下方表单和模块 tab，但主路径始终给出一个明确下一步。素材步骤必须以已保存的 `source_material` 为完成标准，避免用户只输入内容但未沉淀资产时被误判为已完成。

### 10.2 首单生产向导规则

| 步骤 | 规则 |
|---|---|
| 选任务 | 默认选择“生成一条口播视频”，用户可切换到公众号、直播或反转短剧 |
| 用示例填素材 | 根据当前任务填充项目名、账号定位、选题名称、素材标题和主题/原文内容 |
| 点下一步 | 根据 `nextWorkflowAction` 执行创建项目、创建选题、保存素材或进入生成模块 |

首单生产向导不使用弹窗，保持在生产中心页面内，避免遮挡已有表单和模块。

## 11. 异常与降级

| 场景 | 处理方式 |
|---|---|
| 用户未选择任务 | 默认展示“生成一条口播视频”，仍允许直接操作项目和素材 |
| 未创建项目 | 流程提示当前卡在“建立 IP 档案”，保存素材时沿用自动创建逻辑 |
| 未创建选题 | 流程提示当前卡在“创建内容选题”，保存素材前自动创建或提示用户创建 |
| 素材为空 | 生成入口禁用或提示先输入主题、链接或原文 |
| 素材已填写但未保存 | 仍提示保存素材，不进入内容生成步骤 |
| 后端接口失败 | 保留当前选择的任务、项目、选题和素材输入，展示可理解错误 |
| 旧用户熟悉模块入口 | 保留现有 5 个生产模块 tab，不强迫走新手引导 |

## 12. MVP 范围

| 范围 | 功能 |
|---|---|
| 必须做 | 顶部任务入口、首单生产向导、推荐流程导览、任务选择后推荐下一步、保留现有项目/选题/素材/模块 tab |
| 应该做 | 根据任务切换默认输入方式、目标平台、示例素材和推荐模块；在总览页展示任务路径 |
| 可延后 | 完整新手向导弹窗、个性化任务推荐、跨项目模板推荐、任务完成率分析 |
| 暂不做 | 新增复杂工作流编排器、重写现有公众号/口播/提词器模块、自动发布 |

## 13. 数据埋点

| 事件 | 含义 |
|---|---|
| production_task_selected | 用户选择了哪个生产任务 |
| production_example_started | 用户是否点击“用示例开始” |
| production_step_reached | 用户到达了哪个生产阶段 |
| production_material_saved | 用户是否完成素材输入 |
| production_target_tab_opened | 用户进入了公众号、小红书/口播、提词器或高级视频 |
| production_delivery_completed | 用户完成草稿箱、提词器、出片或导出交付 |

## 14. 验收标准

- 生产中心顶部可以看到 4 个面向用户任务的入口。
- 用户可以在首单生产向导中点击“用示例开始”，自动填充当前任务的示例选题和素材。
- 提示词工具需要单独列出，并明确不是生产链步骤。
- 用户选择任务后，可以看到该任务对应的推荐生产顺序。
- 推荐生产顺序至少覆盖任务选择、IP 项目、内容选题、素材输入、内容生成、交付出口。
- 现有 `IP 项目`、`内容选题`、`素材输入` 表单能力不被破坏。
- 现有 5 个生产模块 tab 仍为 `选题总览`、`公众号闭环`、`小红书/口播`、`提词器`、`高级视频`。
- 选择公众号任务后，推荐下一步可以进入公众号闭环。
- 选择公众号任务后，“用示例开始”会填充公众号长文示例，并显示原文输入框。
- 选择口播或直播任务后，推荐下一步可以进入小红书/口播或提词器。
- 选择直播任务后，“用示例开始”会填充直播话术示例，并显示主题输入框。
- 用户填写素材但未保存时，流程仍停留在“输入素材”，下一步动作仍是保存素材。
- 选择反转短剧任务后，推荐下一步可以进入高级视频入口。
- 移动端下任务卡片和流程步骤应单列展示，不遮挡现有表单。

## 15. 实施阶段

| 阶段 | 目标 | 交付内容 |
|---|---|---|
| 第 1 步 | 文档入库 | PRD、文档索引、生产中心流程说明 |
| 第 2 步 | 前端引导层 | 任务卡片、首单生产向导、流程步骤、推荐下一步 |
| 第 3 步 | 任务到模块映射 | 根据任务切换默认输入方式、目标平台和目标模块；提示词工具独立入口 |
| 第 4 步 | 验收和回归 | 构建检查、E2E 冒烟、移动端布局检查 |
