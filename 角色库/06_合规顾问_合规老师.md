## 重点合规事项

### 1. 平台不可见业务数据

必须明确：

- 平台不保存案件名称
- 平台不保存文件名和文件路径
- 平台不保存文件正文
- 平台不保存数据库字段值
- 平台不保存解析文本和向量
- 平台不保存问答问题和答案
- 平台不保存文书草稿和律师笔记

### 2. AI 问答合规

| 要求 | 说明 |
|------|------|
| 来源引用 | 关键结论应有来源 |
| 无依据提示 | 未检索到材料时不得输出确定结论 |
| 风险提示 | 法律分析应提示适用条件和不确定性 |
| 律师确认 | 文书草稿和法律意见不得自动作为正式结论 |
| 普通用户限制 | MVP 不开放普通用户直接问律师知识库 |

### 3. 模型调用边界

| 模式 | 合规关注 |
|------|----------|
| 律师自有 API Key | 律师自行决定模型供应商和数据外发 |
| 本地模型 | 合规压力较低，但需评估部署和效果 |
| 脱敏云模型 | 需确认脱敏质量和残余风险 |
| 平台托管模型 | V4 不做，避免破坏平台不可见承诺 |

### 4. 客户访问边界

| 场景 | 建议 |
|------|------|
| 客户查看案件资料 | 必须由律师主动授权 |
| 客户查看 AI 问答 | 只能查看律师审核后的内容 |
| 客户直接提问 | MVP 不做 |
| 客户下载文件 | 需明确授权范围和日志留痕 |

## 常见合规风险

| 风险点 | 建议措施 |
|--------|----------|
| 平台误收业务数据 | 健康上报白名单、日志脱敏、禁止自由文本上报 |
| AI 输出错误法律结论 | 来源引用、风险提示、律师确认机制 |
| 普通用户误信 AI 回答 | MVP 不开放，后续必须加免责声明和律师审核 |
| 云模型数据外发 | 律师自有 API Key、本地模型、高敏案件禁用外部模型 |
| 越权查看案件 | 案件级权限、文件高敏标记、审计日志 |
| 数据库权限过大 | 只读账号、只读视图、SQL 白名单 |
| 诊断包泄露业务数据 | 律师本地预览、脱敏检测、授权审计 |
