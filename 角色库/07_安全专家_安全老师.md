## 数据分类与保护策略

### 数据敏感度分级

| 级别 | 数据类型 | 保护措施 |
|------|----------|----------|
| **极敏感** | 案件正文、数据库字段值、问答内容、文书草稿、模型 API Key | 仅 Agent 本地保存，加密存储，平台不可见 |
| **高敏感** | 文件名、文件路径、当事人、客户信息、律师笔记 | 本地权限控制，禁止上报平台 |
| **中敏感** | 文件元数据、任务日志、错误详情 | 本地保存，脱敏后才可诊断 |
| **低敏感** | Agent ID、版本、在线状态、任务计数、错误码 | 可按白名单上报平台 |

### 敏感数据处理

```text
存储：Agent 本地加密 + 最小权限
传输：业务数据默认不传平台；必要传输必须 HTTPS/TLS
展示：高敏字段脱敏展示
访问：角色权限 + 案件权限 + 审计日志
销毁：支持本地索引、缓存、问答、凭证清理
```

## 安全架构设计

### 1. 平台不可见边界

| 项目 | 要求 |
|------|------|
| 平台数据库 | 不得保存案件、文件名、正文、问答、向量、数据库字段值 |
| 平台 API | 不得接收业务正文 |
| 健康上报 | 只允许白名单字段 |
| 平台日志 | 不得出现业务内容 |
| 平台支持 | 只能查看律师授权的脱敏诊断包 |

### 2. Agent 本地安全

| 措施 | 说明 |
|------|------|
| 本地鉴权 | Agent 管理台和案件工作台必须登录 |
| 凭证加密 | 数据库密码、模型 API Key 本地加密 |
| 任务隔离 | 解析、OCR、向量化任务需绑定组织和案件权限 |
| 审计日志 | 本地记录访问、下载、导出、问答、删除、授权 |
| 离线策略 | 平台不可用时本地已授权功能可继续运行 |

### 3. 数据库安全

| 措施 | 说明 |
|------|------|
| 只读账号 | 数据库连接账号不得具备写权限 |
| 只读视图 | 推荐由律所技术人员创建授权视图 |
| SQL 白名单 | 只允许 SELECT，禁止 INSERT/UPDATE/DELETE/DDL |
| 字段映射审计 | 映射变更需留痕 |

### 4. AI 安全

| 措施 | 说明 |
|------|------|
| Prompt Injection 防护 | 文档内容不得作为系统指令执行 |
| 模型外发控制 | 高敏案件可禁用外部模型 |
| 律师自有 API Key | 平台不代理模型请求 |
| 无依据提示 | 防止 AI 编造法律依据 |

## 应急响应预案

### 数据或凭证泄露处理流程

```text
1. 发现：识别泄露类型和影响范围
2. 隔离：暂停相关 Agent、账号或凭证
3. 止损：轮换数据库密码、模型 API Key、SSH Key
4. 排查：分析日志、权限、上报字段和访问记录
5. 通知：按合规要求通知相关负责人和用户
6. 修复：修补漏洞、调整权限、更新白名单
7. 复盘：形成报告，更新安全策略和测试用例
```
