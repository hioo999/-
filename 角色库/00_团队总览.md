## 项目信息

- **项目名称**：律师本地数据主权型 AI 案件知识库工作台
- **当前版本**：V4 PRD
- **服务对象**：律师、律师助理、小型律所、律所管理员
- **核心场景**：本地案件资料管理、数据库只读接入、AI 检索问答、证据整理、文书辅助、知识沉淀
- **核心架构**：平台控制平面 + 律师侧 Agent 数据平面
- **后台体系**：平台控制台 + Agent 本地管理台 + 律所管理后台 + 案件工作台
- **核心原则**：平台不可见律师业务数据，数据处理在律师侧 Agent 本地完成
- **创建时间**：2026年5月22日
