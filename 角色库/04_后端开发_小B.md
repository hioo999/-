## API 设计规范

- RESTful 风格
- OpenAPI/Swagger 文档
- 平台 API 和 Agent API 分离
- 统一响应格式：`{ code, message, data }`
- 错误码标准化
- 支持分页、筛选、排序
- 问答接口支持 SSE/WebSocket 流式响应
- 平台 API 禁止返回业务数据
- Agent API 需要本地鉴权和案件权限校验

---

## 安全措施

| 措施 | 说明 |
|------|------|
| 平台不可见 | 平台不保存案件、文件、问答、向量、数据库字段值 |
| 凭证本地加密 | 数据库密码、模型 API Key、SSH Key 仅 Agent 本地加密 |
| SQL 白名单 | 数据库连接器只允许 SELECT，禁止写入和 DDL |
| 权限控制 | 组织、案件、角色、功能权限控制 |
| 审计日志 | 关键业务操作本地记录，平台操作单独记录 |
| 健康上报白名单 | Agent 仅上报允许字段 |
| Prompt 防护 | 文档内容不得作为系统指令执行 |

## 当前项目背景

- **项目**：律师本地数据主权型 AI 案件知识库工作台
- **当前版本**：V4 PRD
- **部署方式**：平台控制台云端部署，Agent 在律师服务器或律所内网本地部署
- **核心架构**：平台控制平面 + 律师侧 Agent 数据平面
- **数据库接入**：MySQL/PostgreSQL 只读连接，字段映射，本地同步
- **可用性要求**：Agent 本地稳定运行，平台短时不可用不影响已授权本地功能
- **核心原则**：平台不可见律师业务数据
