## 重点测试场景

### 1. Agent 部署和激活

- Agent 安装启动
- 授权码激活
- 平台只看到 Agent ID、版本、在线状态
- 平台不出现业务数据

### 2. 平台不可见测试

| 测试点 | 验证内容 |
|--------|----------|
| 平台数据库 | 不存在案件名、文件名、正文、问答、向量、数据库字段值 |
| 健康上报 | 只包含白名单字段 |
| 错误日志 | 不包含业务内容 |
| 平台页面 | 不出现案件、文件、问答、文书入口 |

### 3. 数据库连接器测试

- MySQL/PostgreSQL 只读账号连接
- 表/视图选择
- 字段映射
- 文件路径关联
- 手动同步
- 写入 SQL 被拒绝
- 高权限账号风险提示

### 4. 案件工作台测试

- 创建案件
- 绑定目录/文件/数据库记录
- 文件解析状态
- 案件问答
- 引用来源跳转
- 摘要和争议焦点确认
- 证据目录生成和编辑

### 5. 权限测试

| 角色 | 验证权限 |
|------|----------|
| 平台管理员 | 只能看授权、Agent 状态、脱敏健康 |
| Agent 管理员 | 管本地目录、数据库、模型、任务、日志 |
| 律所管理员 | 管本律所成员、角色、案件权限 |
| 主办律师 | 管理自己的案件和成员授权 |
| 协办律师 | 查看和编辑被授权案件 |
| 助理 | 上传资料、整理证据、发起解析 |
| 只读成员 | 只能查看和检索，不能修改 |

### 6. AI 问答测试

- 有来源回答
- 无来源拒答或提示不足
- 相反材料提示
- 引用文件名、页码、原文片段
- AI 推断内容标记
- 高敏案件不保存问答

### 7. 异常测试

- 数据库连接失败
- 本地目录无权限
- 文件解析失败
- OCR 失败
- 向量库不可用
- 模型 API 超时
- 平台离线时 Agent 本地功能可用
